# VISUAL_DESIGN.md — 비주얼 기준 (스타터)

이 문서가 **톤의 정본**이다. 기계용 짝은 옆의 `palette.json` 이고, UI·FX 생성기가 그 파일을 읽는다.
색을 바꾸려면 **`palette.json` 한 곳만** 고치고 두 생성기를 다시 돌린다. 스펙 파일에 hex 를 직접
박으면 그 순간 톤이 갈라지기 시작한다.

> 프리셋: **밝은 캐주얼 퍼즐** — 하늘색 주조 + 골드 보조. 게임에 맞게 바꿔 쓰라고 넣어둔 출발점이지,
> 정답이 아니다. 장르가 다르면 아래 "정할 것" 표를 채우는 것부터 다시 한다.

## 1. 색

| 그룹 | 쓰임 | 토큰 |
|---|---|---|
| `primary` | 주 버튼·강조·기본 UI | `@primary.light` `.base` `.dark` `.outline` |
| `accent` | 보상·구매·시선 끌 곳 | `@accent.*` |
| `neutral` | 비활성·보조 | `@neutral.*` |
| `surface` | 패널·팝업 바탕, 눌린 홈 | `@surface.white` `.tint` `.sunken` |
| `state` | 성공·위험·경고 | `@state.success` `.danger` `.warning` |
| `ink` | 그림자 | `@ink.shadow` `.deep` |
| `fx` | 이펙트 색 (primary/accent에서 파생) | `@fx.hit` `.pop` `.combo` `.coin` |

**`fx` 그룹이 `@accent.light` 처럼 다른 토큰을 가리키는 게 핵심이다.** 주조색을 바꾸면 이펙트 색도
따라 바뀐다 — UI는 파란데 이펙트만 보라색으로 남는 사고가 구조적으로 막힌다.

## 2. 형태 규칙

| 항목 | 값 | 왜 |
|---|---|---|
| 버튼 라운드 | 높이의 약 28% (112px → 32) | 캐주얼 톤. 각지면 유틸리티 앱처럼 보인다 |
| 외곽선 | 5px (버튼) / 6~7px (패널·팝업) | 작은 화면에서 요소 분리. 얇으면 배경에 묻힌다 |
| 외곽선 방향 | **안쪽으로** | 바깥으로 그리면 실제 규격이 커져 레이아웃이 밀린다 |
| 상단 하이라이트 | 높이의 40%, 알파 0.45 | 볼록해 보이게. 눌림 상태에서는 0.18로 낮춘다 |
| 그림자 | y+7, blur 7 (눌림 y+2) | **그림자 이동이 눌림의 주 신호다.** 색만 바꾸면 안 눌린 것 같다 |

## 3. 상태 변형 규칙

| 상태 | 색 | 그림자 | 하이라이트 |
|---|---|---|---|
| normal | `light → base` | y+7 | 0.45 |
| pressed | `base → dark` (한 단계 어둡게) | **y+2** | 0.18 |
| disabled | `neutral.light → neutral.base` | y+5, 알파 0.25 | 0.20 |

**픽셀 규격은 세 상태가 완전히 같아야 한다.** 크기가 1px이라도 다르면 누를 때 덜컹거린다.
생성기는 같은 `w/h/pad/radius` 를 쓰므로 이 조건이 자동으로 지켜진다.

## 4. 이펙트 규칙

- 알파 = 밝기. Additive·Alpha-blend 양쪽에서 동작하게 굽는다
- **첫 프레임이 가장 밝고, 마지막 프레임은 완전히 사라진다** (남으면 화면에 자국)
- 루프 이펙트(`combo`)는 마지막↔첫 프레임이 이어져야 한다
- 검수는 **어두운 배경**에서 (`_preview.png`). 흰 배경에서는 흰 코어가 사라져 판정이 안 된다

## 5. 접근성·가독성

- 텍스트는 `@ink` 계열, 배경은 `@surface` 계열 — 본문 대비 4.5:1 이상
- **한국어·영어 둘 다 넣어 확인한다.** 한글이 더 넓고, 폰트에 글리프가 없으면 `□`로 나온다
  (실측 사례: `⛔`·`✕` 가 NotoSansKR SDF 에 없어 두부로 렌더됨)
- 색만으로 상태를 구분하지 않는다 (형태·아이콘 병행)

## 6. 생성

```bash
node <플러그인>/skills/ui-art-system/scripts/ui-kit-gen.mjs ui-spec.json --out art/ui
node <플러그인>/skills/fx-art-system/scripts/fx-gen.mjs     fx-spec.json --out art/fx
```
`palette.json` 이 스펙 옆에 있으면 자동으로 잡는다(`--palette` 로 지정도 가능).
