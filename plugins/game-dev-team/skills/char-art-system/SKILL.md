캐릭터는 UI(`ui-art-system`)·이펙트(`fx-art-system`)와 다르다. 저 둘은 결과물이 **규격**이라 코드로 그리는 게 정확하지만, 캐릭터는 **인상**이 결과물이라 생성 모델이 필요하다.

## 전제 — 백엔드

로컬 ComfyUI 가 `http://127.0.0.1:8188` 에 떠 있어야 한다. 세팅: **[references/comfyui-setup.md](references/comfyui-setup.md)**
(RTX 50 시리즈는 CUDA 12.8+ PyTorch 가 아니면 커널 없이 죽는다 — 가이드의 경고 항목을 먼저 본다.)

**안 떠 있으면 "생성 실패"가 아니라 `측정 불가`로 보고한다.** 되돌아갈 곳이 프롬프트가 아니라 환경이다.

## 이 축의 본질은 정체성이다

"예쁜 캐릭터 한 장"은 쉽다. 어려운 건 **같은 캐릭터가 포즈·앵글·표정이 바뀌어도 같아 보이는 것**이다. 강도 순:

| 방법 | 강도 | 언제 |
|---|---|---|
| 시드 고정 | 약 | 같은 구도 변주만 |
| IP-Adapter / reference-only | 중 | 시안 단계, 세팅 쉬움 |
| **캐릭터 LoRA 학습** (시안 10~20장) | 강 | **양산 단계. 여기까지 가야 자동화다** |

## 실행 (백엔드가 떠 있을 때)

```bash
node <플러그인>/skills/char-art-system/scripts/comfy-run.mjs \
  <플러그인>/skills/char-art-system/references/workflows/sdxl-character.api.json \
  --out art/char --batch 8 --seed 1000 \
  --set 6.text="<프롬프트>"
```

- `--batch N` 으로 시안을 한 번에 N장. **시드는 자동으로 기록된다**(`run-log.json`)
- `--set <노드id>.<입력>=<값>` 으로 프롬프트·해상도·스텝을 바깥에서 바꾼다. 워크플로 파일은 안 건드린다
- 서버가 없으면 스크립트가 **`측정 불가`** 로 끝난다 — 실패로 처리하지 않는다
- **배치가 끝나면 모델을 자동으로 내린다.** SDXL 하나가 커밋 10GB 를 잡는다(실측 14.6GB → 4.4GB).
  연속으로 돌릴 때만 `--keep-loaded` 를 준다 — 그 경우 다음 배치가 모델 재로딩 90초를 아낀다.
- 작업이 다 끝났으면 서버도 내린다. 모델은 디스크에 남으므로 재다운로드는 없다.

워크플로는 `references/workflows/` 에 API Format 으로 둔다. 웹UI 에서 새로 만들었으면
**"Save (API Format)"** 으로 저장해야 한다(일반 Save 는 `/prompt` 가 400 으로 거부).

## 절차

1. **기준 확인** — `VISUAL_DESIGN.md` 의 팔레트·프로포션·금지 스타일을 프롬프트에 넣는다. 없으면 `art-direction` 부터.
2. **시안 배치 생성** — 한 캐릭터당 8~16장. 시드를 전부 기록한다.
3. **자동 스코어링** — 규격(캔버스·배경 순도·알파 여백) + 팔레트 정합 + 실루엣 판독성. 하위는 자동 탈락.
4. **사람 채택** — 상위 3장에서 1장. **이 한 단계는 남긴다** (취향·IP·톤은 사람 판단).
5. **정체성 고정** — 채택본으로 LoRA 학습하거나 IP-Adapter 레퍼런스로 등록.
6. **변형 양산** — 표정·포즈·의상 변형. 프레임 시트가 필요하면 `sprite-pipeline` 으로 넘긴다.
7. **등록** — `asset-pipeline` manifest 에 **모델·시드·프롬프트·LoRA 버전**까지 적는다.

## 재현성 (이 축에서 제일 자주 깨지는 것)

생성물은 **모델 + 시드 + 프롬프트 + LoRA 버전** 이 없으면 다시 만들 수 없다. 6개월 뒤 스킨 하나 추가하려는데 원본 캐릭터를 재현 못 하면 처음부터 다시 그리게 된다.

manifest 에 반드시 남긴다:
```
checkpoint / lora(+가중치) / seed / sampler·steps·cfg / 프롬프트 원문 / 레퍼런스 이미지 경로
```

## 보고 (검증 리포트 5섹션)

- **증거**: 실행한 워크플로와 `prompt_id`, **시드·생성 장수·채택 기준**, 결과 경로
- **기준**: `VISUAL_DESIGN.md` 의 어느 항목과 대조했는지
- **공백**: 안 만든 변형(표정·앵글), 스코어링 못 한 항목
- **잔여 위험**: 정체성이 흔들릴 수 있는 변형 범위

## 하지 않는 것

- 톤·팔레트 결정 (`art-direction` 소관)
- 프레임 시트 정규화·아틀라스 (`sprite-pipeline` 소관)
- 실존 IP·타 게임 캐릭터를 모방한 생성 — 레퍼런스는 스타일 기준이지 복제 대상이 아니다
- 백엔드가 없는데 "대충 비슷한 결과"로 넘어가기 — 그건 `측정 불가`다
