# 도트 보정 규칙 받아오기 — 아티스트 인계 양식

도트 보정 도구를 만들려면 **규칙이 숫자로** 있어야 한다. 이 문서는 그 숫자를 받아오는 절차다.

## 원칙 — "규칙 알려주세요"보다 "고쳐주세요"가 낫다

도트 찍는 사람은 **손으로 안다.** 추상적으로 물으면 추상적인 답이 온다
("깔끔하게", "계단이 예쁘게"). 그걸로는 도구를 못 만든다.

대신 **우리 결과물을 주고 고쳐 달라고 한 뒤 전후를 기계로 잰다.**
그러면 규칙이 아니라 **그 사람이 실제로 한 일**이 나온다. 임계값도 거기서 나온다 —
내가 눈대중으로 정하면 멀쩡한 걸 기각한다(실제로 세 번 그랬다).

## A. 보내는 것

1. **원본 스프라이트 2~3장** (PNG, 투명 배경, 축소 전 상태와 축소 후 상태 둘 다)
2. 현재 팔레트 (`palette.json` 또는 색 목록)
3. 게임 표시 크기 (예: 96px)
4. 아래 "요청문" 그대로

### 요청문 (복사해서 전달)

> AI로 뽑은 도트 스프라이트입니다. **게임에 넣을 수 있는 수준으로 고쳐 주세요.**
>
> - 다시 그리지 마시고 **보정만** 해주세요. 어디를 왜 고쳤는지가 저희한테 중요합니다
> - 디자인(포즈·장비·색 선택)은 바꾸지 말아 주세요
> - 고친 파일과 **원본을 둘 다** 주세요 (같은 크기, 같은 위치)
> - 작업하면서 "이건 규칙이다" 싶은 게 있으면 한 줄씩 메모해 주시면 큰 도움이 됩니다
>
> 저희가 전후를 비교해서 **자동 보정 도구**를 만들려고 합니다.
> 매번 손으로 고치시지 않아도 되게 하는 게 목적입니다.

**마지막 문장이 중요하다.** 일을 뺏는 게 아니라 반복을 없애는 것이라고 분명히 해야
제대로 된 협조가 나온다.

## B. 받은 뒤 우리가 재는 것

전후 PNG 한 쌍이면 아래가 전부 기계로 나온다.

| 재는 것 | 무엇을 알려주나 |
|---|---|
| 대각선 런렝스 분포 (전/후) | **계단 정리 규칙.** `2-2-2` 로 맞추는지, 1픽셀 튐을 없애는지 |
| 색 수·팔레트 차집합 | 색을 줄였는지 늘렸는지, 어떤 색을 버렸는지 |
| 외곽선 픽셀의 색 분포 | 외곽선을 쓰는지, 단색인지 색상별인지 |
| 재질별 명암 단계 수 | "한 재질에 몇 단계까지" |
| 고립 픽셀 비율 (전/후) | 어디까지 지우는지 — **상한이 여기서 나온다** |
| 바뀐 픽셀의 위치 분포 | 어디를 주로 손대는지 (얼굴? 외곽선? 그림자?) |
| 실루엣 변화 | 형태를 건드렸는지 (건드렸으면 "보정"이 아니라 "리터치"다) |

## C. 그래도 말로 받아야 하는 것

전후 비교로 안 나오는 **정책**은 물어야 한다. 짧게.

1. **외곽선** — 쓰나? 쓰면 단색인가, 재질마다 다른가? 두께는 항상 1px인가?
2. **명암 단계** — 한 재질에 몇 단계? (우리 실측: 상용 도트 300장 중앙값 22색)
3. **디더링** — 쓰나? 쓰면 어떤 패턴(Bayer 2x2/4x4)? 어디에만?
4. **안티에일리어싱** — 도트 안에서 중간색을 허용하나, 아니면 금지인가?
5. **반투명** — 완전 금지인가? (우리 실측: 상용 300장 중 **91%가 반투명 0%**)
6. **게임 표시 크기에서만 보는가** — 확대해서 보는가, 실제 크기로만 판단하는가

## D. 절대 하지 말 것

**받은 규칙을 바로 하드 게이트로 박지 마라.**

순서는 이렇다:

1. 규칙을 **보정 도구**로 구현한다 (막지 않는다)
2. 여러 장에 돌려 **전후 비교를 아티스트에게 보여준다**
3. 아티스트가 "이건 과하다 / 이건 부족하다"로 임계값을 정한다
4. **그때** 게이트로 승격한다

2~3 을 건너뛰면 멀쩡한 결과를 기각한다. 이 레포에서 세 번 났다 —
외톨이 상한 15%(15/16장 기각) · 타일 이음매 `+0.5`(7장 중 5장 기각) ·
`--enclosed` 를 캐릭터 구분 없이 적용(눈·이빨·뼈 소실).
전부 **규칙은 맞았고 임계값이 틀렸다.**

## E. 샘플 1장이면 시작할 수 있다

전부 갖출 때까지 기다리지 마라. **스프라이트 한 장의 전후**만 있어도
계단 런렝스·색 수·외곽선·고립 픽셀 네 가지는 바로 뽑힌다.
거기서 나온 규칙으로 도구 1차를 만들고, 그걸 다시 보여주면서 좁혀 가는 게 빠르다.
