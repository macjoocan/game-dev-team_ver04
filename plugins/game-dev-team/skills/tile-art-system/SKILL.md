타일은 **"예쁜 한 장"이 아니라 "반복해도 티가 안 나는가"가 결과물이다.**
생성 모델은 매번 다른 그림을 주므로 상하좌우가 이어지지 않는다. 이어 붙이는 건 기하 문제라 코드가 맞다.

```bash
node skills/tile-art-system/scripts/tile-gen.mjs <spec.json> --out tiles [--palette <pal.json>]
# 판정: 0 이음매 없음 · 1 이음매 발견(버그) · 2 입력 오류
```

## 이음매 없음은 검사하는 게 아니라 보장하는 것이다

노이즈 격자 인덱스를 **타일 크기로 모듈로 감싼다.** 그러면 `x=W` 의 값이 `x=0` 과 **정의상 같다** —
눈으로 맞추는 게 아니라 수식이 보장한다. 실측 주기성 오차 **0.000e+0**.

그래서 도구의 이음매 검사는 품질 검사가 아니라 **회귀 검사**다. 0 이 아니면 노이즈 구현이 깨진 것이다.

**게이트는 임의 임계값으로 박지 마라.** 첫 판에 `이음매 <= 내부평균 + 0.5` 로 박았다가
7장 중 5장을 잘못 반려했다(2026-10-02). 마지막 열과 첫 열은 **한 칸 이웃**이라 차이가 나는 게 정상이다.
지금은 **타일 안의 모든 이웃 열/행 차이 분포**와 비교한다 — 이음매가 그중 최댓값보다 크지 않으면
"보통 자리"와 구분되지 않는다. 같은 실수를 [[feedback-gate-calibration]] 에서도 했다.

## 전이 타일이 없으면 화면이 가짜로 보인다

바닥 타일만 만들면 잔디와 흙이 **칼로 자른 듯 직각으로** 만난다. `transitions` 를 주면
코너 기반 16장을 낸다.

**왜 코너 기반인가:** 네 모서리가 각각 A/B 인 16가지를 만들고, 픽셀 소속은 네 코너값의
**쌍선형 보간**으로 정한다. 윗변 위의 값은 좌상·우상 코너에만 의존하므로
**위 타일의 아랫변과 정의상 일치한다** — 이웃 타일을 몰라도 이어진다.

경계를 울퉁불퉁하게 만드는 노이즈는 **모든 타일이 같은 한 장을 본다.**
타일마다 시드를 바꾸면 공유 변에서 어긋난다.

## 팔레트를 캐릭터와 공유해라

`--palette` 로 캐릭터 팔레트(`palette-force` 가 쓰는 것과 같은 파일)를 주면 스펙의 색을
가장 가까운 팔레트 색으로 당긴다. 배경이 다른 팔레트를 쓰면 **화면에서 바로 티가 난다.**

```bash
node .../tile-gen.mjs spec.json --out tiles --palette <캐스트>/palette.json
```

## 스펙

```json
{
  "tileSize": 32,
  "materials": [
    { "name": "grass", "seed": 11, "variants": 3, "grain": 6, "octaves": 3, "contrast": 1.4,
      "colors": ["#5c8f4a", "#4a7c3f", "#3c6634"],
      "speckle": { "color": "#6fa15a", "density": 0.03, "size": 1 } }
  ],
  "transitions": [
    { "from": "grass", "to": "dirt", "seed": 71, "edgeGrain": 6, "edgeSeed": 909, "edgeAmp": 0.35 }
  ]
}
```

- `colors` 는 **밝은 쪽부터** 적는다. 연속 그라디언트가 아니라 **계단**으로 끊어 칠한다(도트는 단계다)
- `variants` 를 늘리면 반복감이 준다. `grain` 은 무늬 크기 — 작을수록 잘다
- `edgeAmp` 가 크면 경계가 더 울퉁불퉁해진다. 0 이면 쌍선형 그대로(매끈한 곡선)

## 이 도구가 판정하지 않는 것

- **지루한가.** 이음매가 0 이어도 무늬가 반복돼 티가 날 수 있다 — `variants`·`grain` 으로 푼다
- **어울리는가.** 팔레트를 공유해도 톤이 맞는지는 사람이 본다
- **레벨 배치.** 어느 칸에 무엇을 놓을지는 기획·개발 몫이다. 여기서는 재료와 규칙(코너 마스크)만 낸다

`preview.png` 는 **오토타일로 깐 결과**다. 무작위 배치가 아니라 코너 격자를 만들어
전이 타일을 실제로 사용한다 — 전이가 어긋나면 여기서 바로 보인다. **수치가 통과해도 이걸 봐라.**
