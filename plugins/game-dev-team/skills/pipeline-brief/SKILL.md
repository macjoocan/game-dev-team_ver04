파이프라인 상태를 짧게 요약해 사람이 "다음에 뭔 결정/승인해야 하는지" 즉시 알게 한다.

## 절차
1. **`PIPELINE_STATE.md`를 먼저 읽는다**(레포 루트) — 현재 단계·게이트 통과 이력·미결이 기록된 정본.
   없으면 setup-game-team의 `references/pipeline-state-template.md`로 생성을 제안한다.
2. 소스 수집(연결된 것만): GitHub(열린 PR·리뷰 대기·실패 CI·오래된 브랜치), 트래커(진행/블로커 이슈),
   레포 상태(AGENTS.md/CLAUDE.md 게이트·미결 목록).
3. 파이프라인 단계별로 매핑: 기획/게임성검증/구현/QA/아트/경제/폴리싱 중 어디에 무엇이 걸려 있나.
4. **사람의 결정이 필요한 게이트**를 최상단에 별도로 모은다.
5. 브리핑 후 상태가 변했으면(게이트 통과/반환 등) `PIPELINE_STATE.md`를 갱신한다.

## 산출물 (짧게)
- **승인/결정 대기**: (있으면) 게이트 목록 — 사람이 바로 판단할 것.
- **진행 중**: 단계별 1줄.
- **블로커/위험**: 리뷰 지연·실패 CI·미결 등.
- **오늘 추천 액션**: 1~3개.
> 장황 금지. 예약 작업(매 평일 오전)으로 돌리면 상시 대시보드 역할.
