# 체형이 다른 이족 캐릭터의 발 관통·손 파고듦 고치기

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-31 |
| 과제 | 키·팔 길이가 제각각인 이족 크리처에서 발이 바닥을 뚫고 손이 몸에 파고듦. 자기 동작을 고칠 수 있는지, 다른 체형의 동작을 나눠 쓸 수 있는지 확인 |
| 조건 | 대상: 키 2.66m, 골반 1.71m, 팔이 무릎까지 내려옴. Humanoid 뼈 24개, 동작 10개. 비교 체형: 키 2.41m, 골반 1.54m, 짧은 팔. 뼈 이름·동작 이름이 같음 |
| 상태 | **시범 완료.** 자기 동작 + (c) 보정은 쓸 만함. 다른 체형 동작 공유는 안 됨 |

> 아래 수치는 **한 사례의 값**이다. 다른 모델에 옮겨 쓰지 않는다.

## 후보

| 후보 | 방식 |
|---|---|
| (a) 지금 | 원래 클립. 다른 체형 동작은 뼈마다 "기본 자세 대비 회전 변화"를 옮기고, 골반 이동은 골반 높이 비율로 맞춤 |
| (b) 발 고정 | 디딘 구간을 **발 속도**로 찾아(디딘 발은 일정한 속도로 뒤로 감) 발바닥을 직선 경로·바닥 높이에 고정. 다리 2마디 IK, 무릎 방향은 원래 무릎을 따라감. 다리가 못 닿으면 골반을 내림 |
| (c) (b) + 팔 벌림 | 손·아랫팔이 몸통·다리에 파고들면 위팔을 몸 바깥으로 벌림(2°씩, 최대 40°). 벌리는 축은 몸이 보는 앞 방향. 각도는 프레임마다 구한 뒤 5프레임 최대 → 7프레임 평균으로 부드럽게 이음 |

지표:
- 손-몸 파고듦: 손·아랫팔 정점이 몸통·머리·다리 표면 안으로 들어간 최대 깊이(8cm 안의 마주 보는 표면만, 기본 자세 값 뺌). 괄호는 1cm 넘게 들어간 정점 수.
- 디딘 동안 발 높이 오차: 디딘 구간에서 발바닥 최저점이 바닥에서 떨어진 최대 거리(위·아래 모두).

## 확인한 것

| 함정 | 처리 | 근거 |
|---|---|---|
| **자기 동작인데도** 발이 바닥 아래로 최대 24cm | 동작을 만든 원본의 다리가 이 캐릭터보다 길었던 것으로 보인다. 자기 동작이라고 검사를 건너뛰지 않는다 | (a) 24.9cm |
| 발만 고치면 손 파고듦이 늘어남 | 골반을 내리면 팔이 다리 쪽으로 내려온다. 발 고정 뒤에 팔 보정을 같이 한다 | (b) 5.0 → 7.9cm |
| 팔 벌림 각도가 프레임마다 튐 | 프레임별 각도를 그대로 쓰면 팔이 떨린다. 최대 → 평균 두 번 평활한다 | 렌더 |
| 다른 체형 동작을 그대로 입힘 | 짧은 팔용 동작이라 긴 팔이 허벅지를 뚫는다(정점 155개). (c)로 고치려면 팔을 36~40° 벌려야 해서 동작 성격이 바뀐다 | 수치 + GIF |

## 채택·이유

- **결론: 체형이 크게 다르면 동작을 나눠 쓰지 않는다.** 캐릭터마다 자기 리그에 만든 동작을 쓰고 (c) 보정으로 발·손을 맞춘다.
- 자기 동작 + (c): 바닥 관통 11~25cm → 0.5~2.5cm. 팔은 4~14°만 벌어져 동작 모양이 거의 그대로다.
- 2026-10-23 교훈("동작을 만든 리그에 메시를 맞춘다", 손 오차 5mm vs 196mm)과 같은 방향이다.

## 적용 범위와 반례

- 적용 범위: 비율이 제각각인 이족 크리처·캐릭터의 이동·손 동작.
- 체형 차이 대응 순서(조사 결과):
  1. 캐릭터마다 비율표(골반 높이·팔다리 길이·어깨 폭·머리·배 크기)와 동작 지표를 같은 표로 뽑는다.
  2. 걸음 폭은 다리 길이에 맞춘다: 기준 속도 × (대상 골반 높이 ÷ 원본 골반 높이).
  3. 디딘 발은 IK로 고정한다(Unreal IK Retargeter의 Speed Planting과 같은 생각).
  4. 손이 몸 안에 들어가면 몸통 부피(캡슐 몇 개) 밖으로 밀어낸다.
  5. 손이 입·머리에 닿는 프레임은 그 몸 부위 기준 위치 × 부위 크기로 옮긴다.
- 반례·미확인
  - "비슷한 체형"의 기준(골반 높이·팔 길이 비율)은 아직 안 정했다.
  - 게임 쪽 실시간 IK로 같은 보정을 하는 것은 아직 안 했다.
