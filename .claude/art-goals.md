## "아트 한 벌"의 정의

목표 3이 달성됐다고 말하려면 산출물 단위가 있어야 한다. **한 벌 = 게임 하나가 굴러가는 최소 아트 세트:**

| | 수량 | 내용 |
|---|---|---|
| 캐릭터 | 주인공 1 + 적 3 + 보스 1 | 정지 · 걷기 · 공격 · 피격 |
| UI | 1세트 | 버튼 4상태 · 패널 · 바 · 아이콘 8 · 프레임 |
| 이펙트 | 1세트 | 타격 · 소멸 · 획득 · 충전 |
| 배경 | 타일셋 1종 | 바닥 · 벽 · 장식 |
| 출구 | 전부 | 시트 + manifest(프레임·fps·피벗·9-slice) |

**이 한 벌이 손 작업 0으로 나오면 목표 3 달성이다.** 두 번 나오면(일반 2D 한 벌 + 도트 한 벌)
목표 1·2도 같이 닫힌다.

## 기준은 실측으로 잡는다

목표 2("도트도 잘")의 "잘"은 취향이 아니라 숫자다. 이미 상용 도트 300장에서 뽑아놨다:

- 색 수 중앙값 22 (16~32 = 52%)
- **91% 가 반투명 픽셀 0%**
- lonely 9.1% (IQR 6.3~10.8) · flat 14.3% (IQR 11.1~18.4)
- **어두운 외곽선 없음** (27% 만 가장자리가 더 어둡다 — 내 가정이 틀렸었다)

새 축을 열 때도 같은 방식으로 간다: **레퍼런스를 실측 → 하드 게이트와 화풍 지표를 분리 →
게이트로 건다.** 한 건으로 좁게 박지 않는다([[feedback-gate-calibration]]).
