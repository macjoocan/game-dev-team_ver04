# 자동 플레이테스팅 전략 — 검증 강도 사다리

balance-sim의 AI 정책을 게임의 전략 깊이에 맞게 단계적으로 강화하는 가이드.
원칙: **싼 방법부터.** 아래 단계는 위 단계가 부족할 때만 올라간다.

## 1단계 — 규칙 기반 봇 (기본, 대부분 충분)
- 무작위 정책 + 휴리스틱 정책(탐욕적 최선 수) 최소 2종으로 상·하한을 본다.
- 비용: 거의 0. 속도: 초당 수천 판. 재현성: 시드 고정으로 완전 재현.
- 한계: 사람다운 전략·콤보 발견 못 함 → 픽률/승률의 "하한 추정"으로만 해석.

## 2단계 — LLM 플레이어 (전략 깊이가 있을 때)
- 게임 상태를 텍스트로 직렬화해 LLM에게 수를 고르게 한다(콤보·시너지 인식 가능).
- 용도: 휴리스틱이 못 찾는 지배 전략·카드 시너지 발견, "사람이라면 이렇게 깬다" 시나리오.
- 비용: 판당 토큰 소모 → 수십~수백 판 샘플링용(몬테카를로 대체 아님, 1단계와 병행).
- 참고: LLM 에이전트 기반 게임 테스팅 연구 — https://arxiv.org/html/2509.22170v1

## 3단계 — RL 에이전트 (밸런스가 수익에 직결될 때)
- Unity면 ML-Agents(PPO)로 자동 플레이 학습. 커버리지를 높이려면 curiosity 보상 추가.
- 용도: 인간 테스터가 못 찾는 엣지 케이스·익스플로잇 대량 발굴, 난이도 곡선 실측.
- 비용: 학습 인프라+시간. 정식 밸런스 파이프라인이 있는 프로젝트용.
- 참고: 자율 에이전트 밸런스 평가 — https://arxiv.org/pdf/2304.08699
- 참고: curiosity 기반 플레이테스트 커버리지 — https://arxiv.org/pdf/2103.13798

## 해석 규칙 (공통)
- 정책이 다르면 지표도 다르다 — **리포트에 어떤 정책으로 얻은 수치인지 명시**한다.
- 봇 승률 ≠ 사람 승률. 목표 지표는 "휴리스틱 봇 기준 X%" 처럼 정책 기준으로 정의한다.
- 어떤 단계든 RNG 시드 고정·재현 가능해야 게이트 근거로 인정한다.
