# 네발 캐릭터의 발 미끄러짐·관통을 보행 생성기와 클립 기반 가중치로 고치기

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-30 |
| 과제 | 이미 게임에 들어간 네발 크리처의 이동 동작에서 발이 바닥을 뚫고 미끄러짐. 다리를 움직이면 살이 크게 늘어남. 뼈대와 동작 이름은 그대로 두고 고치기 |
| 조건 | 생성 모델(텍스처 이음매마다 정점이 갈라진 메시) + 사람이 손으로 붙인 네발 뼈대(뼈 21개, **발 뼈 없음**). 동작 34개, Generic. 이동 클립은 제자리 동작 |
| 상태 | **제안까지.** (b) + w3 권함. 사람 외형 확인과 게임 반영은 아직 안 함 |

> 아래 수치는 **한 사례의 값**이다. 다른 모델에 옮겨 쓰지 않는다.

## 먼저 알아 둘 것 (2026-10-30 문서 기준)

| 도구 | 네발 리깅 | 네발 동작 |
|---|---|---|
| Meshy 웹 | 됨 (Quadruped Dog) | 걷기만 붙음 |
| Meshy API | **안 됨** (사람형만) | 없음 |
| Tripo API | 됨 (네발·여섯다리·새 등) | 프리셋 몇 개 |
| Blender Rigify | 기본 뼈대 있음 | 직접 만듦 |

- 어려운 쪽은 리깅보다 **동작**이다. 자동 도구가 주는 네발 동작은 걷기 정도뿐이다.
- 연구용 동작 생성(AnyTop·Kirin 등)은 라이선스를 확인하기 전에는 게임에 쓰지 않는다. MANN·DeepPhase는 코드·데이터가 상업 사용 불가라 방법만 참고한다.

## 후보

동작:

| 후보 | 방식 |
|---|---|
| (a) 지금 | 원래 클립 |
| (b) 다리 생성 | 몸통·머리·혀는 원래 클립 그대로. 다리만 발 목표 경로 + 2마디 IK로 다시 만듦 |
| (c) 전부 생성 | 기본 자세에서 몸 흔들림까지 만듦 |

보행 생성 방법:
1. 다리마다 박자를 다르게 준다. 걷기 = 뒷왼 0, 앞왼 0.25, 뒷오 0.5, 앞오 0.75. 속보 = 대각선 한 쌍씩 0·0.5.
2. 디딘 동안 발은 일정한 속도로 뒤로 간다(제자리 클립). 든 동안은 앞으로 호를 그린다.
3. 발 이동 폭·디딘 시간·드는 높이는 원래 클립에서 잰 값을 쓴다.
4. 발 뼈가 없으면 아랫다리가 기울 때 발바닥도 같이 구른다. IK 뒤에 **발바닥 메시를 직접 재서** 디딘 동안 그 자리·높이에 고정한다(3번 반복).
5. 길이는 원래 클립과 같게, 처음과 끝이 이어지게 만든다.

가중치:

| 후보 | 방식 |
|---|---|
| w0 | 지금 가중치 |
| w1 | Blender 자동 가중치(heat) |
| w2 | 지금 + Delta Mush(주변 정점과 섞어 부드럽게 만든 모양) 굽기 |
| w3 | heat + 굽기 |

- 굽기 자세는 실제 클립 10개에서 4프레임마다 뽑았다(86자세). 다리에 붙은 정점과 바깥 두 겹만 다시 푼다.

## 확인한 것

| 함정 | 처리 | 근거 |
|---|---|---|
| 생성 모델 메시에서 자동 가중치(heat)가 모든 정점 0 (10배로 키워도 0) | 텍스처 이음매로 표면이 조각나서다. 정점을 합친 복사본(열린 모서리 14,506 → 4)으로 계산하고 가장 가까운 정점에 옮긴다 | 모든 정점에 가중치 생김 |
| 굽기 뒤 몸통에 검은 실금 | 같은 자리 정점이 서로 다른 가중치를 받아 이음매가 벌어졌다. 겹친 정점 묶음은 가중치를 평균해 같게 맞춘다 | "이음매 벌어짐" 지표 0 |
| 지표는 좋은데 그림이 이상함 | 위 실금은 늘어남 지표에 안 잡혔다. 지표와 렌더를 같이 본다 | 렌더 비교 |
| 다리 영역을 후보 가중치로 고름 | 후보마다 다른 정점을 재게 된다. 영역은 **위치로** 고정한다 | 재측정 |
| 발 미끄러짐 판정이 흔들림 | 바닥 2cm 기준이면 발을 들고 내리는 순간이 섞인다. 0.5cm + 디딘 구간 양 끝 1프레임 제외를 모든 후보에 같게 적용한다 | 재측정 |
| 발 뼈가 없는 리그 | IK 목표만 맞추면 발가락이 바닥을 파고든다. 발바닥 메시를 재서 목표를 고친다 | (b) 관통 0.8cm |
| 뼈대를 바꾸고 싶어짐 | 뼈대를 바꾸면 기존 동작 34개가 깨진다. 뼈대는 두고 동작·가중치만 후보로 비교한다 | 범위 결정 |

## 채택·이유

- **제안: 이동 클립은 (b) 다리 생성, 가중치는 w3.** 사람 결정은 아직 없다.
- 이유
  - (b)는 원래 동작의 몸짓을 살리면서 발만 고친다. (c)는 수치는 더 좋지만 몸짓이 단순해진다.
  - w3는 모든 늘어남 지표가 가장 낮다. 입 동작에서도 이빨·혀가 뭉개지지 않았다(렌더 확인).

## 적용 범위와 반례

- 적용 범위: 뼈대를 못 바꾸는 네발(또는 다리 여러 개) 캐릭터의 **제자리 이동 클립**.
- 반례·미확인
  - 기절·묶임처럼 누운 자세 클립 13개는 바닥 기준이 달라 범위에서 뺐다.
  - 경사·계단은 게임 쪽 발 IK가 필요하다. 아직 안 했다.
