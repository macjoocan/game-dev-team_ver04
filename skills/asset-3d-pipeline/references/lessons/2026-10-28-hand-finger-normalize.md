# 실사 손 리그의 손가락 뼈를 메시 모양에 맞춰 정상화하기

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-28 |
| 과제 | 실사 캐릭터 5명과 좀비 1명의 손가락 뼈가 실제 손가락과 어긋나 주먹을 쥐면 손이 구겨짐. 손가락 뼈를 메시 모양에 맞추고 가중치를 다시 만들기 |
| 조건 | 실사 FBX(면마다 정점이 갈라짐) + GLB 캐릭터 1종. 손가락 30뼈. 동작은 다른 FBX와 공유하는 Generic |
| 상태 | **도구 완성.** Blender 애드온의 손 도구로 정리. 결과 FBX는 로컬 보관(게임 반영은 동작 골격 결정 뒤) |

> 아래 수치는 **한 사례의 값**이다. 다른 모델에 옮겨 쓰지 않는다.

## 순서

1. **정점 합치기**(노멀 유지). 면마다 정점이 갈라져 있으면 손가락 찾기·자동 가중치가 안 된다.
2. **손가락 찾기**: 손 뼈 가중치(> 0.05) 정점을 손 방향(PCA) 높이로 손끝부터 채우는 병합 트리를 만든다. 큰 덩어리 1 + 버틴 길이 상위 4 가지 = 5손가락.
3. **이름 붙이기**: 손끝이 가장 낮은 가지 = 엄지. 엄지에서 가까운 순서로 검지~새끼. 뿌리 관절은 갈림 지점보다 손가락 길이 12% 손바닥 쪽.
4. **자동 가중치**: 임시 복사본에 Blender 자동 가중치를 걸고 손 영역 값만 옮긴다.
5. **Delta Mush 굽기**: 손가락 굽힘 자세로 주변 정점과 섞은 모양을 가중치로 굽는다.

## 수치

오른손 주먹 늘어남(mm):

| 캐릭터 | 전 | 후 |
|---|---:|---:|
| 실사 1 | 32 | 12 |
| 실사 2 | 28 | 16 |
| 실사 3 | 38 | 18 |
| 실사 4 | 51 | 16 (렌더는 아직 구겨짐) |
| 좀비 | 46 | 13 |

- 손가락 가지 길이는 5명 모두 3~9cm로 뚜렷했고, 잡음 가지는 0.2cm 미만이었다.

## 확인한 것

| 함정 | 처리 | 근거 |
|---|---|---|
| 큰 덩어리에서 맨 위 손가락을 뗄 때 검지 + 중지가 한 덩어리로 나옴 | 이미 합쳐진 다른 가지의 정점은 빼고 뗀다 | 가지 길이 표 |
| 손바닥 쪽을 "엄지 끝이 있는 쪽"으로 정함 | 엄지가 손 평면에 붙은 리그에서 뒤집힌다. 손가락 방향 × (검지 → 새끼) 방향으로 정하고, 오른손은 부호를 반대로 한다. **판정은 굽는 면 옆에서 렌더로 확인** | 렌더 |
| GLB 캐릭터의 뼈 끝·축이 이상함(뼈 길이 2m) | Blender가 GLB 뼈 끝·축을 추측한다. 뼈 tail·로컬 축을 믿지 말고 관절 머리 사이 방향으로 굽힘 축을 계산한다 | 뼈 비교 |
| 가중치 기준으로 뼈 맞추기 | 실사 모델은 가중치가 손가락 경계를 넘어 퍼져 실패한다. **메시 모양 기준**으로 맞춘다 | 실패 사례 |
| "뒤집힌 면" 지표가 너무 큼 | 뼈 회전을 빼지 않으면 손끝 170° 회전을 접힘으로 센다. 뼈 회전을 빼고 센다. 갈라진 정점 짝의 벌어짐(찢어짐)은 따로 잰다 | 지표 비교 |
| 기준을 고친 뒤에도 결과가 이상함 | 틀린 굽힘 방향으로 이미 굽었다. 기준을 고치면 굽기를 **원본에서** 다시 한다 | 재작업 |
| 사람이 관절 점을 클릭으로 하나만 잡아 떼어 냄 | 박스 선택해야 이어진 점이 같이 움직인다. 손가락 첫 마디를 손목에 모으면 손바닥까지 접힌다 | 사람 작업 |
| 동작을 공유하는 Generic 캐릭터 | 동작에 손가락 30뼈 위치·회전 키가 있어 손뼈 기본 자세를 바꾼 FBX를 넣으면 게임에서 손이 틀어진다(뼈 회전 10~31° 차이). 넣기 전에 동작 골격과 맞출지, 동작을 다시 내보낼지 정한다 | 비교 |
| 동작을 뗀 뒤 굽기 | 라이브 Blender에서 동작을 떼면 몸이 마지막 자세로 남는다. 굽기 전에 포즈를 초기화한다 | 재작업 |

## 주먹 자세

- 마디를 모두 85°로 똑같이 굽히지 않는다. 손가락 90 / 80 / 60°.
- 엄지 첫 마디는 손가락 방향 축으로 45° 가로지르고, 2·3마디는 50 / 60°. 엄지가 검지·중지 앞을 덮는 주먹이 된다(엄지-검지 6.3cm).
- 남은 구김은 보정 셰이프 키로 처리한다.

## 적용 범위와 반례

- 적용 범위: 손가락 뼈가 실제 손가락과 어긋난 리그(실사 스캔, 생성 모델, 다른 데서 가져온 리그).
- 반례·미확인: 손가락이 서로 붙은 메시(장갑·벙어리장갑)는 병합 트리로 가지가 안 갈린다 [확인 필요].

## 검사 통과 / 외형 승인

| 구분 | 상태 |
|---|---|
| 검사 | 주먹 늘어남, 뒤집힌 면(뼈 회전 뺌), 찢어짐 |
| 외형 승인 | 사람이 Blender 렌더로 확인. 게임 안은 동작 골격 결정 뒤 |

## 놓친 것

- 손바닥 방향을 한 리그로만 확인했다. 리그마다 굽는 면 옆 렌더를 먼저 봤으면 뒤집힘을 바로 잡았다.
- 동작 공유 여부를 늦게 확인했다. 손뼈를 고치기 전에 **그 손이 어떤 동작으로 움직이는지**부터 본다(2026-10-30 교훈과 같음).
