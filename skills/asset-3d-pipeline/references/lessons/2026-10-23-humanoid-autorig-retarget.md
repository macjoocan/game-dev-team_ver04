# 자동 리깅 동작을 기존 Humanoid 캐릭터에 붙이기

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-10-23 |
| 과제 | 자동 리깅 서비스로 만든 새 리그의 이모트 동작 12종을, 이미 게임에 있는 사람형 캐릭터(Unity Humanoid)에 붙이는 방법 정하기 |
| 조건 | 사람형 캐릭터 + 자동 리깅 서비스 + Unity Humanoid. 새 리그는 기존 캐릭터와 루트 이름·휴식 자세·척추 마디 수가 다름 |
| 상태 | **완료.** (c) 채택(사람 결정) |

> 아래 수치는 **한 사례의 값**이다. 다른 모델에 옮겨 쓰지 않는다.

## 후보

| 후보 | 방식 | 다른 점 |
|---|---|---|
| 기준 | 이모트 FBX에서 자기 아바타로 Humanoid 임포트. 기존 캐릭터 + 기존 아바타 그대로 재생 | 기준 |
| (a) 척추 3마디 매핑 | 기존 캐릭터에 Spine/Chest/UpperChest 3마디를 매핑한 확인용 아바타를 붙여 재생 | 아바타 매핑 |
| (b′) 손 IK만 | 기존 아바타 그대로 + 클립의 손 목표 위치로 손 IK | IK만 |
| (b) 매핑 + 손 IK | (a) + 손 IK | 매핑과 IK |
| (c) 새 리그 메시 | 리타깃 없음. 자동 리깅 서비스가 리그를 붙인 같은 캐릭터 메시로 재생 | 재생하는 메시를 바꿈 |

같은 클립을 같은 카메라(정면·측면·뒷면·손 근접)·같은 fps로 렌더한다.

- 손 오차: 원본 뼈 그대로(Generic) 재생한 손 위치와 비교. 위쪽 척추 기준 손 위치를 팔 길이로 나눠 대상 팔 길이로 환산. 체형 차이도 들어 있음
- 어깨 늘어남: 어깨·위팔 정점 사이 변이 첫 프레임보다 가장 많이 늘어난 길이

## 수치

12종 평균(mm). 괄호는 최대.

| 후보 | 손 오차 | 어깨 늘어남 |
|---|---:|---:|
| 기준 | 196 (541) | 219 (495) |
| (a) 척추 3마디 매핑 | 109 (191) | 229 (484) |
| (b′) 손 IK만 | 84 (181) | 223 (495) |
| (b) 매핑 + 손 IK | 38 (75) | 229 (484) |
| **(c) 새 리그 메시** | **5 (41)** | **99 (190)** |

거꾸로 확인(기존 캐릭터의 동작을 새 리그 메시에 Humanoid로 재생, 어깨 늘어남 최대 mm):

| 기존 동작 | 기존 캐릭터 | (c) 새 리그 메시 |
|---|---:|---:|
| 대기 | 124 | 60 |
| 달리기 | 177 | 70 |
| 당기기 | 439 | 195 |

12종 전체(기준 + Height Offset) 측정:

| 지표 | 값 |
|---|---|
| 발 미끄러짐 | 2종은 1cm 이하. 나머지 10종은 6.5~23.5cm. 원본 동작에 발 디딤이 섞여 있음 |
| 반복 이음새 | 반복 클립 4종 중 1종이 21.5°(손)·골반 19.2cm. 나머지 3종은 0 |
| 바닥 | Height Offset 적용 후 관통 0.1cm 이하. 앉는 동작은 적용 전 26cm 가라앉음 |

## 확인한 것

| 함정 | 처리 | 근거 |
|---|---|---|
| 손이 원본과 어긋남 | 원인은 클립이 아니라 **재생하는 쪽 아바타**. 기존 아바타가 척추를 Spine 1마디로만 매핑해, 원본 3마디 굽힘이 어깨 밑에 몰림. 임포트 경고에 중간 척추 뼈 회전을 버린다고 나옴 | (a)에서 196 → 109mm |
| 기존 캐릭터 아바타를 Copy From Other로 빌리면 실패 | 루트 이름이 달라 Unity가 거부한다. 매핑만 복사하면 휴식 자세가 달라 다리가 들린다. 이모트 FBX에서 **자기 아바타**를 만들어 Humanoid로 임포트한다 | 배치 임포트 로그, 렌더 |
| 손 IK만으로는 부족 | 손 위치만 맞추면 손 오차는 줄지만 어깨 늘어남은 그대로 | (b′) 84 / 223, (b) 38 / 229 |
| 배치 렌더에서 동작이 멈춘 것처럼 찍힘 | 재생 위치를 바꿔도 SkinnedMeshRenderer가 다시 스키닝되지 않는다. 매 프레임 `BakeMesh`로 구워 렌더한다 | 렌더 비교 |
| 클립마다 발 높이가 다름 | 클립마다 Height Offset(`level`)으로 가장 낮은 메시 점을 바닥 0에 맞춘다 | 오프셋 없음 뜸 3.0cm → 적용 후 0 |
| Humanoid는 추가 뼈 동작을 버림 | 손가락·턱 동작이 필요하면 Generic으로 가져온다 | 이전 작업 기록 |

## 채택·이유

- **채택: (c) 새 리그 메시로 캐릭터 교체** (사람 결정).
- 이유
  - 손 오차가 가장 작음(5mm). 다른 후보는 38mm 이상.
  - 어깨 늘어남이 절반 이하(99mm). 매핑·IK 후보는 줄지 않음(223~229mm).
  - 기존 캐릭터 동작 3종도 새 리그 메시에서 어깨 늘어남이 절반 이하.
- (b)는 기존 외형을 지키지만 오차가 남아 비교용으로만 둠.
- 대가: 기존 캐릭터 메시를 바꾸는 일이라 외형 보존 규칙·승인 절차가 걸린다. 기존 동작 전체, 재질·UV, 머리 뼈 기준 부착점(눈·장비 소켓)을 다시 확인해야 한다.
- 기존 FBX는 덮어쓰지 않고 새 FBX를 추가한다. 기존 FBX를 다른 파생 동작·재질의 원본으로 쓰는 곳이 있을 수 있다.

## 적용 범위와 반례

- 적용 범위: 자동 리깅 서비스의 새 리그 동작을, **척추 마디 수·루트 이름·휴식 자세가 다른** 기존 Humanoid 캐릭터에 붙일 때.
- 먼저 볼 것: 재생할 캐릭터 아바타의 척추 매핑(Chest·UpperChest 유무)과 임포트 경고.
- 반례·미확인
  - 같은 서비스 리그로 만든 캐릭터끼리는 아바타 복사가 될 수도 있다 [확인 필요].
  - 기존 동작은 3종만 거꾸로 확인했다. 전체는 교체 작업에서 확인한다.
  - 원본 FBX와 리타깃 결과의 이음새가 다른 클립이 있었다(원본 7.0°, 리타깃 후 0°). 원인 [확인 필요].
