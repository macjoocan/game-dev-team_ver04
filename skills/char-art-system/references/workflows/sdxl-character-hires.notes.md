# sdxl-character-hires 워크플로 메모

**API Format JSON 에는 주석 키를 넣지 마라.** `_comment` 를 넣었더니 ComfyUI 가 그것을 노드로
해석해 `/prompt` 가 500 을 냈다(2026-08-21 실측). 설명은 이 파일에 둔다.

- **_file**: 2패스(hires fix) 캐릭터 워크플로. 1패스로 구도를 잡고, 잠재공간에서 1.5배 키운 뒤 낮은 denoise 로 다시 그려 얼굴·눈 디테일을 살린다. 커스텀 노드 없이 내장 노드만 쓴다. 1패스 결과가 뭉개지면 2패스도 못 살리므로, 구도(단일 피사체·세로 프레임)가 먼저다.
- **10**: 1.5배 확대. 1248x1824 는 8GB VRAM 에서 SDXL 2패스가 도는 상한선 근처다
- **11**: denoise 0.42 — 너무 높으면 구도가 바뀌고, 너무 낮으면 디테일이 안 붙는다
