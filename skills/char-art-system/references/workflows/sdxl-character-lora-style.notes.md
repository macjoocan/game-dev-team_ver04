# sdxl-character-lora-style 워크플로 메모

`sdxl-character-lora` 에 **두 번째 LoraLoader(노드 14)** 를 이어 붙인 것이다. 10 = 캐릭터 LoRA(정체성), 14 = 스타일 LoRA(화풍).
체크포인트(4) → 10 → 14 → KSampler(3)·CLIPTextEncode(6, 7). LoRA 는 체인으로 잇는다 — 병렬로 두 개를 4 에 붙이면 둘 중 하나만 먹는다.

- **10**: 캐릭터 LoRA. `lora-eval` 로 고른 (파일, 강도). 정체성은 이쪽이 책임진다
- **14**: 스타일 LoRA. 0.5~0.8 에서 시작한다. 1.0 은 캐릭터 LoRA 를 밀어 얼굴이 학습 화풍의 평균으로 돈다
- **6.text**: `<캐릭터 토큰>, <스타일 토큰>, ...` 순서. 두 토큰이 다 있어야 둘 다 켜진다
- 순서는 바꿔도 결과가 크게 다르지 않지만, **강도 합이 1.6 을 넘으면** 둘이 서로를 망친다. 하나를 올리면 하나를 내린다

스타일 LoRA 학습 데이터 규칙(정체성이 아니라 화풍만 남기려면): **캐릭터마다 1장**, 캡션은 태거로 내용을 전부 적는다.
같은 캐릭터가 여러 장 들어가면 그 캐릭터가 토큰에 붙는다. 상세: `../lora-training.md` 의 스타일 LoRA 절.

API Format JSON 에 주석 키를 넣지 마라 — `_comment` 가 노드로 해석돼 500 이 난다.
