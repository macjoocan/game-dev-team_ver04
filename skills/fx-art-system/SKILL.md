게임 FX 텍스처의 대부분은 **글로우 · 링 · 스트릭 · 스파크의 조합**이다. 이건 절차적으로 그리는 편이 생성 모델보다 정확하고 싸다.

**왜 코드로 그리나** — 생성 모델은 이 셋을 매번 놓친다.
1. **중심 정합** — 파티클 텍스처는 중심이 정확히 맞아야 회전·스케일에서 안 흔들린다.
2. **가산 블렌딩용 배경** — 배경이 완전한 검정/투명이 아니면 화면에 사각형 자국이 뜬다.
3. **프레임 간 밝기 곡선** — 시퀀스는 밝기가 매끄럽게 오르내려야 한다. 프레임마다 다른 그림이면 깜빡인다.

톤·색은 사람이 정하고(`art-direction` → `VISUAL_DESIGN.md`), 그 값을 스펙에 넣어 여기서 양산한다.

## 생성

```bash
node <플러그인>/skills/fx-art-system/scripts/fx-gen.mjs <spec.json> --out <디렉터리>
node ... fx-gen.mjs spec.json --out out --preview-bg "#101C2E"
```

스펙 예:
```json
{
  "effects": [
    { "name": "fx_hit_impact", "type": "impact",  "size": 128, "frames": 8, "color": "#FFE08A", "fps": 30 },
    { "name": "fx_match_pop",  "type": "pop",     "size": 128, "frames": 8, "color": "#8CE9FF", "fps": 24 },
    { "name": "fx_combo_glow", "type": "pulse",   "size": 128, "frames": 8, "color": "#63D2FF", "fps": 12, "loop": true },
    { "name": "fx_coin_get",   "type": "sparkle", "size": 128, "frames": 8, "color": "#FFD54F", "fps": 24 }
  ]
}
```

| type | 쓰임 | 구성 |
|---|---|---|
| `impact` | 타격·충돌 | 흰 코어 플래시 + 퍼지는 충격파 링 + 방사 스파이크 |
| `pop` | 매치 소멸·파괴 | 코어가 빠르게 꺼지고 파편이 바깥으로 확산 |
| `pulse` | 콤보·버프 지속 글로우 | 맥동. **`loop: true` 면 마지막 프레임이 첫 프레임과 이어진다** |
| `sparkle` | 코인·보상 획득 | 4갈래 별 반짝임 + 위로 오르는 스파크 |

## 산출물

```
out/
  <이름>/<이름>_00.png ... _07.png   개별 프레임
  <이름>_sheet.png                    가로 스트립 (엔진에 넣는 건 이것)
  <이름>_preview.png                  검수용 — 어두운 배경에 가산 합성
  manifest.json                       프레임 수·fps·loop·blend·pivot·색
```

**알파 = 밝기**로 굽는다. Additive 셰이더에서도, Alpha-blend 에서도 그대로 동작한다.

## 검수 (중요)

**흰 배경에서 보면 안 된다.** 가산 이펙트는 코어가 흰색이라 흰 배경에서 사라진다 — 실제로 이 스킬의 첫 출력을 흰 배경에서 보고 "코어가 안 나온다"고 오판한 적이 있다. `_preview.png`(어두운 배경 가산 합성)로 판정한다.

체크 항목:
- 첫 프레임에 **코어가 확실히 밝은가** (임팩트는 첫 프레임이 제일 세다)
- 마지막 프레임이 **충분히 사라졌는가** (남아 있으면 화면에 자국이 남는다)
- `loop` 이펙트는 **첫·마지막이 이어지는가**
- 중심이 프레임마다 **안 흔들리는가**
- 스트립 폭 = `size × frames` 인가 (엔진 슬라이스가 이 값에 맞는다)

## 튜닝

색·크기·프레임 수·fps는 스펙에서 바로 바꾼다. 형태(스파이크 개수·충격파 속도·파편 수)는 `fx-gen.mjs`의 `fieldFor()` 안에 타입별로 모여 있다 — **한 곳만 고치면 그 타입 전체가 같이 바뀐다.** 게임마다 다른 값은 코드가 아니라 스펙으로 올린다.

## 엔진 반영

`manifest.json`의 `frames`·`fps`·`loop`·`pivot`을 그대로 쓴다.
- 스프라이트 애니메이션: 스트립을 `size` 폭으로 슬라이스
- 파티클: 시트를 Texture Sheet Animation 모듈에 넣고 `frames` 만큼 타일
- 머티리얼: Additive(또는 Premultiplied). Alpha-blend 로 쓰면 코어가 덜 타오른다

## 하지 않는 것

- 연출 **구현**(타이밍·화면 흔들림·hit-stop) — `polish` 소관
- 캐릭터·배경 같은 회화적 아트 — 생성 모델이 필요하다
- 톤·팔레트 결정 — `art-direction`이 정한 값을 받아 쓴다
