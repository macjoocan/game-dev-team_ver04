# 은빛 잔향 — 첫 번째 성문

은발 검사가 폐허의 세 전투 구간을 지나 성문의 수문장을 쓰러뜨리는 브라우저 액션 샘플이다. 배경·병사·수문장·검 궤적·타격 불꽃·새 피격 자세는 GPT 이미지로 제작했다. 걷기와 베기는 기존 로컬 생성 프레임에 B hi-bit 후처리를 적용했다. 새 유료 영상 생성은 사용하지 않았다.

## 실행

이 폴더에서 다음 명령을 실행한다.

```powershell
python3 -m http.server 8201 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8201>을 연다. `start.ps1`로도 실행할 수 있다. HTML 파일을 직접 여는 대신 로컬 서버를 사용한다. 런타임은 외부 패키지나 API 연결이 필요 없다.

## 조작

| 키 | 동작 |
|---|---|
| A / D 또는 방향키 | 이동 |
| 이동 방향을 두 번 누른 뒤 유지 | 달리기. 방향 버튼도 같은 방식으로 동작한다 |
| J 연타 | 베기·되베기·마무리 베기. 공격 중 다음 한 동작을 예약한다 |
| K | 준비 동작이 긴 강공격 |
| Shift | 짧은 무적 회피 |
| Space | 점프 |
| Esc | 일시 정지·계속 |

터치 기기에는 화면 버튼을 표시한다. 이번 화면 검수는 데스크톱 브라우저의 1615×953 및 960×650에서 진행했다. 모바일 실기기 검수는 아직이다.

## 전투와 제작 파일

- `game.mjs`: 입력·공격·피격·적 상태·스테이지 전환. 화면과 분리했다.
- `main.mjs`: Canvas 표시·HUD·Web Audio 효과음·조작.
- `config.json`: 체력·피해·이동·공격 판정과 전투 구간. 현재 값은 프로토타입 가설이다.
- `feel.json`: hit-stop·흔들림·FX 재생 시간. 실제 게임이 이 파일을 읽는다.
- `assets/manifest.json`: 원화·런타임 파일의 해시와 각 아틀라스의 크기·피벗·프레임 수.
- `prepare-assets.py`: 승인된 방향의 원화와 기존 프레임을 가공하는 로컬 스크립트. 같은 저장소의 `out/`에 둔 기존 모션과 고정된 Sprite Forge 체크아웃을 사용한다. 배포용 게임 실행에는 필요 없다.
- `run-qa.mjs`, `prepare-qa.py`: 검사 실행과 원시 로그 보존.

검사 실행:

```powershell
node --test game.test.mjs
```

자동 검사 결과와 남은 공백은 [REPORT.md](REPORT.md)에 있다. 이 샘플은 사람 플레이 검수 전이다. 스프라이트의 형태 미달을 숨기거나 자동 검사 통과를 재미 승인으로 해석하지 않는다.
