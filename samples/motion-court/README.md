# 검객 · 달빛 훈련장

기존 판타지 모션을 직접 조작하는 concept 샘플. 브라우저 주소:

http://127.0.0.1:8788/samples/motion-court/index.html

## 조작

- A/D 또는 좌우 방향키: 걷기 / Shift + 이동: 달리기 (화면의 달리기 유지 옵션도 가능)
- J: 베기 v5 / K: 찌르기 v4
- H: 피격 모션 시험
- Space: 구르기 (중간 구간 무적, 베기를 취소하고 회피 가능)
- P: 일시 정지 / R: 초기화
- 화면 버튼으로 이동·공격 가능
- 공격 범위와 0.5배속으로 타격 구간 확인

쓰러진 허수아비는 2.8초 뒤 복구한다. 공격마다 대상별 1회 적중. 공격 중 이동·다른 공격은 잠긴다. 구르기로 공격을 취소할 수 있다. ‘허수아비 반격’을 켜면 예고 후 느린 공격이 나온다. 수치와 타격·무적 프레임은 `config.json`의 샘플용 가정이며 밸런스 검증값이 아니다. 대기는 모자·검 가이드를 포함한 Sword_Idle에서 생성했다. 서 있을 때 자동 반복하며 이동·공격·회피 입력으로 즉시 빠져나간다. 점프·적 모션은 생성하지 않았다.

베기 이동량을 게임 위치에 반영해 완료 후 위치가 되돌아가지 않는다. 찌르기 v4에는 앞발 내딛기와 뒤발 따라오기 동작이 있다. 구르기는 제작된 Roll_RM 모션을 제자리 영상으로 만든 뒤 게임에서 170px 이동시킨다. 25프레임을 30FPS로 재생하는 샘플 타이밍이다. 구르기 v3는 캐릭터만 내보내며, 먼지는 dust.js에서 세계 좌표로 별도 그린다. 별도 먼지 FX 옵션은 기본 꺼짐이며 효과 줄이기도 먼지를 끈다. 달리기는 CC0 Sprint_Loop 기반 24프레임/36FPS 루프(25번째 닫힘 프레임 제외), 속도는 310px/s로 걷기 190px/s보다 빠른 샘플 가정이다. 색 변화와 장비 드리프트는 사람 검수 대상이다.

## 실행 및 구조

저장소 루트에서 `python -m http.server 8788`을 실행한다. `clips/`와 `drivers/`가 함께 제공된다. 파일 더블클릭은 JSON/모듈 로딩 때문에 지원하지 않는다. 게임 실행에는 ComfyUI나 외부 API가 필요 없다.

- `engine.js`: 렌더링과 분리된 전투 상태·판정
- `game.js`: Canvas 렌더·키보드·터치·HUD
- `config.json`: 모션 폴더·피해·범위·타이밍·연출
- `alignment.json`: 첫 프레임 기준 키·발 앵커, 클립 전체에 고정 적용
- `manifest.json`: 원본 모션 경로와 해시, concept 상태
- `test/motion-court.test.mjs` (저장소 루트): 중복 타격·방향·공격 잠금·피격·복구·root 이동·idle·먼지 검사

새 캐릭터나 액션을 만들 때는 장비·색·크롭·동작을 다시 검수한다. 샘플 수용은 모션의 production 승인과 별개다.
