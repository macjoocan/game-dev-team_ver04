# GPT 이미지 생성의 24프레임 걷기 재현 시험

## [주장]

2026-10-16, 사용자가 선택한 Ludo24장 걷기를 원화와 함께 참조해 내장 GPT 이미지 생성 경로를1회 시험했다. 유사한 캐릭터의 걷기 시트는 만들었으나, 각 프레임의 보행 자세와 변화량을 동일하게 재현한 결과로는 채택하지 않는다. 정지 이미지 생성 한 번의 시험이며 GPT를 이용한 모든 영상·포즈 제어 방식의 한계로 일반화하지 않는다.

비교 화면은 `index.html`이다. Ludo 선택본과 GPT 결과를 같은24장·13.5FPS·약1.78초 주기로 동기 재생한다. 프레임 이동, 느린 재생, 배경, 표시 크기를 바꿀 수 있다.

## [증거]

기준 커밋 `a6b81bd` · codex · 전 결과 concept.

- 입력1: 기존 깨끗한 검객 원화 `inputs/character.png`.
- 입력2: 선택된 Ludo 원본6~29번째 포즈를6열×4행으로 배치한 `inputs/pose-reference.png`. 입력의 무료 워터마크는 보존했다.
- 실제 요청: `request.json`. 투명 배경,1536×1024,6×4,24장, 같은 캐릭터와 셀별 자세·순서 재현을 요청했다.
- 실행: 내장 `image_gen`1회. 외부 Ludo/Voidless 크레딧이나 별도 OpenAI API 키를 사용하지 않았다. 도구가 정확한 백엔드 모델 ID·과금액을 노출하지 않아 특정 GPT Image 버전이나 비용0으로 기록하지 않는다.
- 생성 원본: `raw/gpt-sheet-v1.png`, 실제1536×1024. 원본 RGBA와 해시를 보존했다.
- 분리: 셀256×256을 행 우선 순서로 정확히24장 분리. 공통 캔버스 전체를128px로 축소했다. 개별 bbox 크기 맞춤, 포즈 수정, 프레임 순서 변경, 루프 구간 선택은 하지 않았다.
- 입력 Ludo 비교 프레임24장의 SHA-256은 기존 선택본과 일치한다.

도구 출력 원문: `qa/gpt-walk.txt` 및 `qa/gpt-walk/sprite-qa.json`, `sprite-qa.md`. sprite-qa 종료 코드1, 미달1건·경고3건.8번째 프레임의 실루엣 IoU0.48로 형태 항목이 미달했다. 고아 섬·구멍·반투명 경계 경고도 기록했다. 걷기 자세 자체가 실루엣을 바꾸므로 이 수치만으로 캐릭터 붕괴를 단정하지 않는다.

시각 관찰에서는 붉은 모자·깃털·망토·갈색 복장과 오른쪽 보행 방향을 대체로 유지했다. 다만 셀별 발·무릎 변화, 비슷한 자세가 반복되는 구간, 팔과 망토의 변화가 참조와 달라 동일한 모션의 재현으로 판정하지 않았다. 브라우저에서 투명 배경 위 두 클립의 표시를 확인했다.

## [기준]

셀 수·파일 수·규격 QA, 비슷한 걷기의 성립, 프레임별 자세와 동작 타이밍의 동일성, 루프의 자연스러움을 분리한다. 24장 생성 성공이나 동일한 재생 FPS를 동작 복제 성공으로 취급하지 않는다.

첫 프레임의 앵커·높이를 클립별 고정해 표시한다. Ludo 워터마크가 알파 경계에 포함돼 순수 캐릭터 크기 비교에는 한계가 있다. 동일 프레임의 무릎·발·지지 자세를 나란히 보고, 첫3장과 마지막3장을 노란 테두리로 구분한다.

## [공백]

1회 시트 생성만 시험했다. 관절 좌표의 정량 비교, GPT의 별도 영상 생성 경로, 포즈 제어 모델과의 결합, 후속 교정 생성, 실게임 적용과 사람 최종 승인은 미실행이다. 원본 Ludo의13.5FPS도 영상 길이에서 계산한 비교용 추정값이다. GPT 시트 자체에는 애니메이션 타임스탬프가 없다.

## [잔여 위험]

현재 결과는 시안으로만 보존한다. 동일한 모션을 안정적으로 확장해야 한다면 원본 동작을 유지하는 제어 경로를 별도로 검증해야 한다. GPT가 만든 비슷한 걷기를 Ludo 선택본의 대체품으로 자동 반영하지 않았다. 기존24장 선택본은 그대로 유지한다.

재조립: `node samples/gpt-walk-reproduction-2026-10-16/prepare-comparison.mjs`. 저장된 생성 원본만 사용하며 새 이미지 생성이나 서비스 크레딧 소비는 없다. 원본 시트·참조 입력·프롬프트·QA를 함께 보관한다.

사람 비교 평가: “ludo 가 짱이네”. 이번 검객 걷기에서는 기존 Ludo24장 추출본의 선호를 유지했다. GPT 결과는 재현 시험 자료로 보존한다. 서비스 전체의 우열이나 새 프로덕션 승인으로 확대하지 않는다.
