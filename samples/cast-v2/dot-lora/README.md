# 도트 — 픽셀아트 LoRA 경로 (2026-10-02)

**"확산 모델은 도트를 못 만든다"는 우리 문장이 틀렸다.** 정확히는 **"맨 SDXL 은 못 만든다"**이고,
픽셀아트 LoRA 를 끼우면 만든다. 같은 체크포인트(SDXL base) · 같은 프롬프트 · LoRA 하나 차이다.

- LoRA: [`nerijs/pixel-art-xl`](https://huggingface.co/nerijs/pixel-art-xl) · 163MB · 무료
- 설치: `ComfyUI/models/loras/` 에 넣으면 재시작 없이 잡힌다
- 배선: `LoraLoader` 를 체크포인트와 KSampler/CLIP 사이에 끼운다.
  **MODEL(0)·CLIP(1) 만 거치고 VAE(2) 는 체크포인트에서 바로 간다** — LoraLoader 에 VAE 출력이 없어서
  거기까지 돌리면 `tuple index out of range` 로 400 이 난다(실제로 밟았다).

## 결과

`vs-downscale.png` 가 한 장으로 말한다 — 왼쪽은 일러스트를 96px 로 줄인 것(얼굴이 비었다),
오른쪽은 LoRA 로 뽑아 96px 로 내린 것(눈·갑옷이 읽힌다).

캐스트 4종 · 공용 24색 · 반투명 0% · **외톨이 0.3~3.7%** · 도트 계약 충족.
(일러스트 축소 경로는 외톨이 2.7~14.3% 였다 — LoRA 쪽이 훨씬 정돈돼 있다)

## 1024px 출력은 격자가 아니다

최빈 런렝스를 재보면 1px 이 지배적이다. LoRA 는 **구성**을 도트답게 바꿀 뿐
VAE 는 여전히 연속 RGB 를 뱉는다. **축소·양자화 단계는 그대로 필요하다.**
달라진 건 원본 구조가 도트 모양이라 축소해도 살아남는다는 점이다.

## 남은 결함 — 발밑 그림자

LoRA 가 캐릭터마다 회색 타원 그림자를 그려 넣는다. 네거티브(`drop shadow, ground shadow,
cast shadow`)로도 안 빠지고, `cutout --deshadow` 도 못 잡는다(그림자가 발에 **붙어 있어** 분리 안 됨).

**색으로 떼면 안 된다.** 그림자색 `#8c888f` 가 갑옷·뼈에도 쓰인다 — 상단에 hero 117px,
lunger 212px, **boss 497px**. 색으로 지우면 갑옷이 뚫린다.

선택지: ① 그대로 둔다(베이크된 그림자로 쓴다) ② 다른 시드를 고른다
③ 공간 기준 제거 도구를 만든다(발 아래 + 회색 + 연결 성분). 사람 판단 대기.
