## 경로

```
Animagine XL 4.0 (태그 프롬프트, hires 없음)
  -> cutout --binary-alpha --feather 0 --trim   (--enclosed 는 boss 만)
  -> 상대 크기 정규화 (설계값, 아래 note)
  -> palette-force --colors 24 --apply   (캐스트 공용 팔레트)
  -> pixel-contract --cast               (합집합으로 판정)
  -> atlas-pack --fps 8
```

`run-log-*.json` 에 프롬프트 본문·모델·워크플로 해시·시드·출력 sha256 이 들어 있다.
이것만으로 재현된다.

## 2026-10-02 수정 — 사람이 잡아준 결함 2건

첫 판에 **흰색이 전부 알파로 빠지고 발이 잘렸다.** 둘 다 내 실수였다.

### ① 흰 갑옷·흰 뼈가 통째로 사라졌다
`cutout --enclosed` 를 켠 게 원인이다. 그 플래그는 **"피사체가 둘러싼 배경"** 을 지우는데,
흰 배경(`#fcfcfc`) 위의 **흰 갑옷·흰 뼈가 바로 그 조건에 걸린다.**
도구 도움말에 *"흰 옷이 있으면 켜지 마라"* 라고 적혀 있는데 내가 그걸 어겼다.

**해법은 임계값 조정이 아니다.** 캐릭터에 굵은 검은 외곽선이 있으므로, 테두리에서 들어오는
flood fill 은 외곽선에서 멈춘다 — `--enclosed` 만 빼면 안쪽 흰색은 저절로 보존된다.

**이 플래그는 프로젝트 단위가 아니라 캐릭터 단위로 정한다.** 오거는 흰 부분이 없고
(보라 피부 + 회색 갑옷, 배경과 거리 76 > tol 26) 다리 사이 틈만 남아서 **오거만** 켰다.

마젠타 배경 생성도 시도했지만 모델이 균일한 단색을 못 그린다(그라데이션 + 이미지마다 다른 색).
크로마키는 배경을 **진짜로 통제할 수 있을 때만** 쓴다.

### ② 발이 캔버스 바닥에 붙어 잘려 보였다
정규화에서 `oy = CANVAS - targetH` 로 딱 붙였다. 피벗이 바닥이어도 **스프라이트 자체에는
여백이 있어야 한다.** `FLOOR = 10px` 을 넣고 `cast-manifest.json` 에 `anchorPx` 를 남긴다.

### 겸사겸사
해골 발밑 붉은 타원(그려진 그림자)은 `--deshadow` 로 안 떼진다 — 배경색이 아니라 **그려진 것**이고
붉은 망토와 같은 색이라 색으로 떼면 망토가 뚫린다. **그림자 없는 다른 시드로 바꿨다**(3102 -> 3103).

### provenance 가 실제로 값을 했다
중간 파일을 지운 뒤 원본이 필요해졌는데, `run-log.json` 의 프롬프트·시드·워크플로 해시만으로
**치수까지 똑같이 재현**됐다(826x1169 등). 손으로 적어둔 게 없어도 됐다.

## 이번에 배운 것

1. **hires 패스가 번짐을 만든다.** 첫 시도(`animagine-character-hires`)에서 가로 줄무늬
   고스팅과 파란 배경이 나왔다. hires 없는 `sdxl-character` 그래프에 체크포인트만
   Animagine 으로 바꾸니 깨끗해졌다.
2. **"white background" 태그가 장식 프레임에 밀린다.** 1차에서 8장 중 6장이 액자·꽃잎·
   풍경을 달고 나와 `cutout` 을 못 썼다. 네거티브에 `ornate frame, border, scenery,
   petals, vignette` 를 넣어야 흰 배경이 나온다.
3. **모델은 상대 크기를 모른다.** 고블린과 오거가 둘 다 프레임을 꽉 채워 같은 키로 나온다.
   상대 크기는 **설계값으로 박아야 한다**(여기서는 0.75/1.0/1.05/1.4).

## note — 도구 구멍 2개

- **상대 크기 보존 정규화가 없다.** `sprite-normalize --fit` 은 각자를 캔버스에 꽉 채워
  상대 크기를 없앤다. 이번엔 스크래치 스크립트로 처리했다.
- `pixel-contract` 가 파일 단위로만 팔레트를 보고 있었다. 공용 팔레트를 나눠 쓰는 캐스트는
  각자 11~18색이라 하한 16 에 걸려 **정상인 캐스트가 통째로 미달**이었다.
  `--cast` 를 추가해 합집합으로 판정한다. 2026-09-14 의 "프레임 -> 시트" 와 같은 계열,
  층위만 다르다.
