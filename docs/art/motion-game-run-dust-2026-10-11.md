# 훈련장 v3 — 달리기와 독립 먼지 FX

## 주장

달리기 클립을 추가하고 Shift + 이동 및 달리기 유지 옵션에 연결했다. 구르기는 먼지 없는 캐릭터 프레임으로 교체했다. 먼지는 세계 좌표의 별도 Canvas 입자로 생성하며 기본 꺼짐이다. 걷기·피격 에셋 경로는 유지했다.

## 증거

- 대상 HEAD: `48413a5` + 작업 트리 변경. 실행: `http://127.0.0.1:8788/motion-game/index.html`.
- 달리기: Quaternius CC0 `Sprint_Loop`, 같은 GLB SHA-256 `1b7bf67866360665426bb99e4c71bd619f19b408453c24e30f0c3071601eee5c`. 측면 90도, 제자리 제어. `out/sprite-lab/action-run-driver/motion.json`에 출처·원본 16/24초·샘플링을 기록했다.
- SCAIL-2 512px/25프레임. CFG 1 결과에는 먼지가 남아 채택하지 않았다. CFG 3/8 steps와 스튜디오 조건으로 달리기 v2·구르기 v3를 다시 생성했고 투명 시트 전체를 시각 확인했다. 그래프·프롬프트·참조·모델 정보는 각각 `action-run-v2-scail/`, `action-roll-v3-scail/`에 보존했다.
- 이전에 승인된 코드 색 보정 방식을 재사용했다. 1-based 13~17번의 RGB만 보정했다. `action-run-v2-color-review/color-qa.json`, `action-roll-v3-color-review/color-qa.json`: 알파 변경 0, 비보정 프레임 원본 바이트 동일. 포즈·크기·알파를 바꾸지 않았다.
- 전투·이동·FX·HTTP/MIME 검사 원문: `out/sprite-lab/motion-game/qa-output.txt`, **exit 0, 28개 검사**. Shift 달리기 전환, 루프, 공격 잠금, 좌우 먼지 방향, 효과 끄기, 기존 공격·회피 판정을 포함한다.
- 연출 수치 감사 원문: `out/sprite-lab/motion-game/feel-audit-v3.txt`, **exit 0**.
- 실제 프레임 25장만 별도 폴더로 검사했다. `action-run-v2-sprite-qa.txt`, **exit 1, 형태 미달**. `action-roll-v3-sprite-qa.txt`, **exit 1, 색·형태 미달**. contact/sheet를 프레임으로 읽은 초기 검사 결과는 최종 근거에서 제외했다.

## 기준

걷기 190px/s, 달리기 310px/s는 샘플 가정이다. 달리기는 닫힘 중복 프레임을 제외한 24프레임/36FPS 루프다. 구르기는 25프레임/30FPS, 이동 170px와 기존 무적 구간을 유지한다. 먼지는 캐릭터 이미지의 캔버스·알파·좌우 반전에 종속되지 않고 게임 세계 좌표로 그린다. `별도 먼지 FX`와 `효과 줄이기`로 끌 수 있다.

## 공백

실제 브라우저 키보드·터치 화면 캡처는 실행 환경 오류로 미실행이다. 로컬 엔진·HTTP 검사와 PNG 전체 프레임 검수는 게임 화면에서의 자연스러움이나 사람 승인을 대체하지 않는다. 이번 신규 달리기와 먼지 없는 구르기의 사람 플레이 평가는 대기다.

## 잔여 위험

중간 색 보정으로 잃어버린 디테일을 복원하지는 못한다. 일부 의상·장비 형태 변화와 알파 경계가 남는다. 구르기 실루엣은 큰 회전으로 변하지만 색 미달도 별도로 남아 있다. 새 샘플은 concept이며 production으로 승격하지 않았다. 먼지는 스프라이트 경계에서는 잘리지 않으나 실제 게임 화면의 외곽에서는 정상적으로 화면 밖으로 나간다.
