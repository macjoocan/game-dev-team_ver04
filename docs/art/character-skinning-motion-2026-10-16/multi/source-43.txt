갱신: 2026-10-16. 이 문서를 계속 갱신한다. 자동 검사와 사람의 외형 승인을 구분한다.

## 표면과 가중치

- 원본 메시의 UV는 loop에 보존하고 정점만 연결한다. 이번 원본 로컬 크기 약1에서 weld 거리 `1e-5` 사용. 다른 크기의 모델에 같은 값을 그대로 적용하지 않는다.
- 먼저 decimate하면 경계 양쪽이 서로 다르게 축소돼 거의 같은 위치에 겹친 면이 남을 수 있다. 위치를 정렬하는 것만으로 같은 가중치가 되지는 않는다.
- 원본 뼈의 tail이 해부학적 자식 방향과 다를 수 있다. heat 계산용 임시 리그만 어깨→팔꿈치→손목, 골반→무릎→발목으로 맞춘다. 실제 원본70뼈 rest·계층은 수정하지 않는다.
- 선형 스키닝과 최대4영향을 Blender/GLB에서 일치시킨다. Blender Preserve Volume만 켜서 웹에서 해결됐다고 보지 않는다.
- 단순 표면 근접 가중치 전사는 원본 외투·머리카락·몸통 가중치를 새 팔로 옮길 수 있어 실패했다.
- 전역 graph smoothing/heat를 UV 분리 상태에 적용한 후보는 뜯김이 더 심했다. 전체 voxel remesh는 UV 전사 외형이 깨져 폐기했다.
- 근접14,439쌍에 같은 가중치를 준 별도 후보는 표면 벌어짐29.52→1.21mm로 개선됐지만 어깨 늘어남 기준은 실패했다. 최종 해결로 쓰지 않는다.

## 턱과 얼굴

- 생성 원본 자체에도 턱 돌출이 있다. 기본 형태와 동작 중 늘어남을 나눠 검사한다.
- 하관에 몸통 가중치가 섞이면 얼굴과 턱이 다르게 당겨진다. 머리 내부는 강체로 유지하고 목에서만 부드럽게 이어준다.
- 이전 턱 보정은 최대29.06mm 뒤로 이동했다. 새 원본 재시도에도 같은 국소 보정을 적용했다. 원본은 덮어쓰지 않는다.

## 모션 보존

- Body/Head/Legs는 이름70개가 같아도 bind가 다르다. 각 파트의 rest를 보존한다.
- 원본 Action Slot과 소수 키 시간을 보존한다. 정수 프레임만 bake하거나 GLB 강제 정수 샘플링을 사용하지 않는다.
- finite, 파일 출력 성공, 행렬 일치만으로 새 메시 외형을 통과시키지 않는다. 정면·측면·뒷면과 극단 자세를 확인한다.
- Motion Remap0.2의 접지/골반/컨트롤/B-Bone 기능은 메시 자동 리깅·가중치 교정 도구가 아니다. README/노하우를 읽고 ZIP/릴리스 보고서 해시를 확인했으며 이 세션에서는 도구 자체를 실행하지 않았다.

## 작업 화면과 공유 규칙

- 실패 후보는 사용자 작업 화면에 노출하지 않는다. 별도 씬·복제본에서 검사하고 성공·실패 모두 원래 씬/동작/시각을 복구한다.
- 파일이 사라진 것처럼 보이면 씬·숨김·메시 존재를 먼저 확인한다. 보존 raw에서 복구하며 추가 생성으로 해결하지 않는다.
- 검증된 변경점은 사용자 지정 세션 `01a13d31-184e-7960-9eac-fed37eccf181`에 근거 경로·한계와 함께 지속 전달한다.
- 미해결 과제는 `01a13d2d-374a-7363-b819-4db64e27e540`에 개선 요청한다. 상대의 결과도 이 프로젝트에서 검증한 뒤 채택한다.
- 전달 시점·메시지ID·적용 여부를 문서와 상태에 남긴다. 상대 자료를 읽은 것과 실제 적용·재검증한 것을 구분한다.

## 원본 시간 키와 전체 라이브러리 추가 확인

`export_animation_mode=NLA_TRACKS`는 이번 Blender5.2.1에서 `export_force_sampling=False`여도 실제 파일이24fps 키로 나왔다. 옵션 설정만 보고 시간 보존을 주장하지 않는다. 내보낸 GLB의 sampler input을 읽어 원본과 대조한다.

현재 대시보드는 MD5 local TRS와 정밀fps/scale sidecar를 읽는다.Root만 Z-up→Y-up으로 변환하고 자식 local TRS는 유지한다. Body/Head/Legs의 bind는 따로 보존하며 같은 이름의 각 스킨 뼈에 local pose를 적용한다.이름집합만의 일치를 의미적 호환 보증으로 쓰지 않는다.

309파일을 디코딩한 결과 실제 타이밍/TRS binary 중복제외278항목,그중 정지포즈5.입력오류0/finite.기존5종 GLB와의 calibration은24/60fps 공통키에서만 비교한 것으로 전체시간 bound가 아니다.별도로 raw 원본 기반 Blender Action을 만들고1050행렬표본 max2.67e-5를 확인했다. native GLB597870개float의 시간/TRS가 binary와 정확히 일치한다.

전체278항목은 지연 로딩한다.브라우저32MiB 캐시/LRU,이전 AnimationClip uncache,비동기선택 순번으로 오래된응답이 최신동작을 덮지 않게 했다.레이아웃390px/실제dist다운로드도확인했다.아직 모든외형/손가락/접지/원작이벤트복원은검증하지않았다.
