# 모션 샘플 게임 — 달빛 훈련장

## 주장

사용자가 만든 모션으로 샘플 게임을 보고 싶다고 요청해, 로컬 브라우저에서 직접 조작하는 2D 훈련장을 구현했다. 기존 걷기·측면 베기 v5·찌르기 v3·피격을 연결한다. 새 에셋 생성이나 유료 API 호출은 하지 않았다. 게임용 모션 최종 승인이나 재미 검증을 주장하지 않는다.

## 증거

- 대상 HEAD: `48413a5` + 작업 트리 변경.
- 실행: `http://127.0.0.1:8788/motion-game/index.html`.
- 산출물: `out/sprite-lab/motion-game/`. 원본 해시·출처 폴더·concept 상태는 manifest에 기록했다.
- Canvas 표현과 전투 로직은 `game.js` / `engine.js`로 분리했다.
- 첫 프레임의 본체 중심과 하단을 기준으로 클립마다 크기·발 기준선을 설정하고, 애니메이션 도중 개별 프레임을 다시 크기 조절하지 않는다.
- 원시 검증 출력: `out/sprite-lab/motion-game/qa-output.txt`, JSON: `qa/verification.json`. 전투 7개 검사와 HTTP/MIME 5개 검사, exit 0.
- 연출 감사 원시 출력: `out/sprite-lab/motion-game/feel-audit.txt`, exit 0 / 경고 2건. 흔들림은 진폭 0으로 사용하지 않는다. 사운드는 모션 비교용 샘플에서 미구현이다.
- 기존 art-gate 기준 측정은 `out/sprite-lab/game-art-baseline/`. 해당 설정은 예전 hex 샘플 검사로, 이 게임 화면 통과 근거로 사용하지 않는다.

## 기준

좌우 이동, 공격 중 이동 잠금, 대상별 공격당 1회 적중, 플레이어 방향과 판정 일치, 피격 후 복귀, 허수아비 복구. 효과 감소·일시 정지·0.5배속·판정 영역 표시를 제공한다. 피해·범위·타격 프레임은 config의 명시된 샘플 가정이다.

## 공백

Browser Node 연결이 Windows sandbox helper 오류로 두 번 종료됐고 CUA 브라우저 연결도 종료됐다. 실제 화면 캡처와 브라우저 키보드/터치 조작 검수는 미실행이다. 서버 응답과 순수 전투 로직 검사는 실제 화면 가독성이나 자연스러운 모션을 증명하지 않는다. 사람 플레이테스트 0명, 성능 프로파일링 미실행. 새 FX 시퀀스와 화면 플래시는 만들지 않았다.

## 잔여 위험

원본 공격의 칼끝 잘림·색 흔들림은 유지된다. 대기는 걷기 첫 프레임을 사용한다. 공격간 자세 연결과 클립별 크기 정합성은 사람의 실제 조작 평가가 필요하다. 공격 동작을 끝까지 보여주는 샘플이라 빠른 콤보 입력은 버퍼링하지 않는다. 고정 허수아비만 있어 적 AI·점프·게임 밸런스는 범위 밖이다.
