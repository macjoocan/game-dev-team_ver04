# 액션 v3: 전방 베기와 칼끝 촬영 범위

## [주장]

사용자 피드백: 베기는 뒤로 가며 베는 것이 어색하므로 전방으로 기울며 베어야 한다. 찌르기는 동작이 적당하고 칼 잘림만 수정한다. 베기의 준비·실행 제어를 전방 체중 이동으로 바꾸고, 두 공격의 촬영 범위를 넓힌다. 결과는 사람 검수용 concept다.

## [증거]

대상 커밋 `48413a5` + 작업 트리 변경.

- [재생성 실행 코드](../../out/sprite-lab/run-action-forward-v3.py), [Blender 제어 도구](../../skills/char-art-system/scripts/blender-walk-driver.py).
- 베기에 `--forward-slash`를 적용했다. 준비 때 후방 기울기를 제거하고 실행 때 골반 +.12, 상체 전방 .28rad, 팔을 전방으로 펼치는 동작을 연결한다. 칼은 정면에서 사선으로 올렸다가 전방 아래로 내려간다.
- 두 공격의 카메라 범위를 2.7→3.4로 넓히고 수평 중심을 +.25로 옮겼다. 내장 image_gen으로 같은 칼 없는 캐릭터에 상단·우측 여백을 확보한 [촬영 범위 레퍼런스](../../out/sprite-lab/reference-padded/reference.png)를 만들었다. 이는 리프레이밍용 생성 이미지이며 기존 원화와 픽셀 단위 동일한 변환이 아니다.
- 찌르기는 기존 관절·칼 좌표를 그대로 사용한다. 제어 동작이 동일해도 생성 모델의 이미지까지 동일하게 유지된다는 보장은 없다.
- [좌표·출력 경계 검사 원문](../../out/sprite-lab/action-v3-qa.json): 베기 준비→실행의 머리·손·손잡이 전진을 측정하고, 찌르기 25프레임의 모든 관절·칼 좌표를 기존 제어와 대조한다. RGBA 불투명 영역의 화면 경계 접촉도 기록한다.
- 512px에서 생성·투명 처리하고 160px 정사각형 검수 캔버스로 내보낸다. 캐릭터 크기와 칼 여백을 함께 확보하기 위한 파일럿 규격이다. 기존 걷기·피격의 파일은 그대로 둔다.
- 실제 생성: 베기 127.28초, 찌르기 133.19초. [실행 기록](../../out/sprite-lab/actions-results.json)에 API job ID가 있다. 두 결과 모두 별도 저장하고 13~17번의 색만 보정했다.
- 좌표 검증: 베기 준비→실행에서 머리 X +0.28724, 칼손 X +0.50745, 손잡이 X +0.51123. 준비 자세보다 머리가 뒤로 물러나는 제어 프레임은 없다. 찌르기 25프레임의 관절·칼 좌표 차이 최댓값은 **0**이다.
- 실제 결과 경계: 베기 10·11번, 찌르기 12~15번에서 알파 foreground가 오른쪽 끝에 닿는다. 시트에서도 칼 잘림이 보이므로 잘림 해결로 보고하지 않는다. 통합 제어·경계 스크립트의 계약은 미완성=3, 측정된 미달=1로 분리했다. [실행 원문](../../out/sprite-lab/action-v3-qa.txt)은 **exit 1**이다.
- 찌르기 모션을 보존한 채 생성 칼을 제거하고 고정 칼을 합성하는 대안을 사용자에게 질문했다. 질문 응답 전에는 해당 합성을 실행하지 않는다. 재사용할 [칼 파츠](../../out/sprite-lab/fixed-sword/sword.png)는 내장 image_gen으로 별도 준비했다.

## [기준]

베는 순간 몸과 손이 오른쪽으로 함께 이동하고 칼이 전방 아래를 향해야 한다. 준비 단계에서도 몸이 뒤로 물러나지 않아야 한다. 찌르기의 기존 관절 좌표는 변경하지 않는다. 두 공격의 칼끝이 캔버스 안에서 완성되어야 한다. 알파와 밝기 보정은 별도 단계로 검증한다.

## [공백]

제어 좌표는 실제 생성된 신체 좌표 검출이 아니다. 게임 내 타격 판정·이동 거리·프레임별 판정 시간·엔진 통합은 미실행이다. 검수 출력 규격 160px는 기존 128px 파일럿과 달라 엔진 사용 전에 액션 간 캔버스·피벗·baseline 규격을 통합해야 한다.

## [잔여 위험]

촬영 범위를 넓혀도 모델이 칼을 길게 만들거나 캐릭터를 확대할 수 있다. 화면 경계 검사는 보조 근거이며 칼의 존재·손 연결·길이·방향은 전체 프레임을 사람이 확인한다. 재생성으로 망토·손·명암 세부가 달라질 수 있다.
