## 제공 횟수·생성기 주의

[Premium 공식 문서](https://www.mcp-for-blender.com/docs/premium)는 이미지 입력 시 Hunyuan3D Standard/High 지원, Tripo는 이미지 입력을 High로 계산한다고 안내. 이번 이미지 Standard 요청은 `provider=hunyuan3d`, `quality=standard`를 명시함.

요금표는 검색 캐시와 직접 조회 내용이 달랐음. 앞서 말한 Pro40/10을 현재 계정의 확정 제공량으로 사용하지 않음. 실제 제공량·잔여량은 계정 패널 확인 필요. 이번 초기3건 외 재생성 없음. ComfyUI 추가 시험은 사람 지시로1건 완료. 합계Standard4건, High 추가0건.

### 비용 절감 목적의 원화 개선

사람 목적은 GPT 이미지 생성 사용량 절약. 추가 GPT 생성 없이 기존 설치 모델로 품질 향상 가능 범위를 확인. 기존 GPT 원화를 SDXL img2img denoise0.28로 로컬 보정한 결과는 얼굴/의상/구도 유지. 순수 로컬 신규 생성과 구분. 기존 Animagine4.0은 공식 태그/CFG5/Euler a/28steps로 별도 신규 원화 시험. 새 모델 다운로드·새3D 생성 없음.

### 기존 모델 개선 결과

[원화4종 비교](http://127.0.0.1:5180/comfy-reference.html). Animagine4.0 태그 방식은 기존 SDXL Base 시험보다 큰 머리의 캐주얼 형태·노란 앞치마·청록 바지 반영이 개선됨. 기존 GPT 입력 없이 로컬 신규 생성. 단,2D 애니 그림체이며 손 세부·3D변환 적합성·동일 인물 변형은 미검증. 모델과 프롬프트 설정을 함께 바꿨으므로 모델 단독 효과로 분리하지 않음.

기존 GPT 원화+SDXL 보정은3D풍 외형 유지에 유리했음. 이 결과만으로 로컬에서 GPT 수준의 새3D풍 원화를 자유롭게 만들 수 있다고 단정하지 않음. 비용 절감 방향: 신규 시안은 로컬 특화 모델 시험, 이미 채택한 기준 원화는 재사용해 로컬 보정. 이후 개선 시험에서 GPT 생성0건·추가3D0건. 로컬GPU시간과 전력 사용은 발생.

재현: `source/comfy/server-animagine.api.json`, `models-animagine.json`, `output-animagine/run-log.json`; 보정은 `server-gpt-guided.api.json`, `output-guided/run-log.json`. 기본 노드만 사용, 새 모델 다운로드/외부 이미지API 없음.
