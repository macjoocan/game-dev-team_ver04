## 다음 세션은 여기서 시작

- 최신 비교 기준은 **새 GPT 은발 v3**다. 사용자는 “오우 좋아졌네”라고 긍정 평가했다. 기존 C 26장도 비교 자료로 보존한다. v3는 8키포즈 후보이며 26프레임과 같은 부드러움이나 출시 승인을 뜻하지 않는다.
- 색·얼굴·의상 방향을 유지하면서 **다리 교차와 칼 든 팔의 앞뒤 동작**을 고친다. v1은 색 분리가 좋았지만 다리 교차가 부족하고 칼 든 팔이 고정돼 있다는 사용자 피드백을 받았다. v3는 C의 0·3·6·9·13·16·19·22번 포즈를 참고했다.
- 전후 비교는 `out/experiments/silver-gpt-qa-20261111/review.html`이다. 저장소 루트에서 `node out/experiments/silver-gpt-qa-20261111/serve.mjs`를 실행하고 `http://127.0.0.1:8231/`을 연다. 왼쪽 v1, 오른쪽 v3이며 같은 8fps다.
- v3 정합성은 충족, 경계 접촉은 0/8장, 최소 여백은 15px다. 피사체 하단 범위는 알파 128 기준 2px다. 작은 분리 영역·내부 빈 공간·프린지 경고는 남아 있다. 실제 게임 에셋은 아직 교체하지 않았다.
- v0.54.0은 공통 입력 검사·잘림 경고·`motion-qa` 관찰 도구를 포함한다. 잘림의 자동 차단과 모션 점수의 자동 승격은 넣지 않았다. `liftRange`는 발 들기 점수가 아니라 하단 윤곽 변화량이다.
- 새 스프라이트도 자동 검사를 통과한 뒤 사용자가 모션 문제를 찾았다. **자동 통과와 자연스러운 보행을 구분한다.** 기존 baseline의 희미한 알파 포함 34px와 피사체 하단 6px를 같은 값으로 설명하지 않는다.
- 피드백 정본은 [v3 선호 기록](../../.review-loop/feedback/chr.silver.gpt-qa-20261111.preference.json)이다. 재생·재검사·남은 작업은 최신 인수인계를 따른다. GPT 원화 유지와 모션의 추가 유료 API·클라우드 GPU를 피하는 방향도 유지한다.

## 2026-11-10 액션 스테이지 기록

- `samples/silver-stage-01/`에 실행 가능한 웹 액션 1스테이지가 있다. GPT 배경·병사·수문장·이펙트와 기존 은발 모션을 연결했다. B hi-bit 후처리를 사용했고 새 유료 영상 생성은 하지 않았다.
- J 연타는 베기·되베기·마무리로 연결된다. 궤적은 기존보다 1.50~1.73배 커졌다. 이동키를 두 번 누르고 유지하면 달린다. 달리기는 기존 걷기 프레임을 활용한 임시 표현이다.
- 사용자는 “오 좋다”라고 평가하고 성과 정리와 푸시를 요청했다. 전투 검사는 15/15이며, 기존 형태 검사 미달과 FX 플래시 대조의 조건부 판정은 남아 있다. 긍정 평가를 출시 승인으로 확대하지 않는다.
- 재생·검사 명령은 최신 인수인계를 따른다. 다음 기술 후보는 [Unity 기본 Particle System으로 GPT 텍스처 조립](unity-particle-vfx-research-2026-11-10.md)이다. 활용 검토만 했으며 Unity 제작기와 엔진 검증은 아직 없다.

- 다음 담당자는 위 인수인계의 원본·검수용 GIF·모델 출처를 먼저 확인하고, 포니테일과 장비 유지 및 프레임별 일관성을 검증한다. 유료 호출은 기존 승인 범위와 구별한다.

### 같은 날 비교 결과와 사용자 선택

- 사용자는 비교 화면에서 “B가 젤 나은데?”라고 평가했다. **B(GPT 걷기 시트 + sprite-gen 후처리)를 다음 개선의 기준으로 선택**한다. 최종 승인이나 엔진 반영 승인으로 확대하지 않는다.
- A의 기본 Rust 변형은 손·검의 뼈대 연결이 맞아도 칼과 하체 그림이 휘었다. 강체 분리 분기는 칼 휨을 줄였지만 파츠 틈과 겹침이 발생했다. 원화 한 장의 자동 리깅 경로는 이번 시험에서 미달이다.
- B는 8프레임에서 포니테일과 검을 유지했고 중복 프레임이 없었다. 자동 QA는 02번 실루엣 IoU 0.48로 exit 1이다. 발 접지 가정 검사도 성립하지 않았다. 자세 변화와 실제 정체성 붕괴를 구분해 보고, 02·06번 다리 교차와 07→00 반복 경계를 우선 검수한다.
- 결과·근거: `out/experiments/gpt-walk-20261106/REPORT.md`. 로컬 재생: `http://127.0.0.1:8193/review.html` (서버가 실행 중일 때). 후보의 전체 품질 순위로 일반화하지 않는다.

### Ludo 선택과 은발 캐릭터 생성 요청

- 후속 비교에서 사용자는 “집 · Ludo 한 주기 24장 이게 젤 좋네”라고 평가했다. 은발 캐릭터도 같은 방식으로 생성해 달라고 요청했다. 후속 경로는 Ludo Hydra로 정했다. B 선호는 이전 A/B 비교 범위의 기록으로 남긴다.
