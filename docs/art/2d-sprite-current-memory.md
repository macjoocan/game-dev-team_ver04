# 현재 작업 메모: 2D 캐릭터 모션

업데이트: 2026-11-06. 정본 인수인계: [은발 검사 걷기 실험](2d-sprite-motion-handoff-2026-11-06.md).

- 사용자는 사람이 제작한 것처럼 자연스러운 2D 게임 아트와 모션을 원한다. 현재 목표는 은발 검사의 부드러운 걷기에서 발 교차·접지·검·포니테일·망토를 함께 유지하는 것.
- 승인된 키포즈를 유지한다. 검이나 발이 사라지거나 뒤집히고, 부츠가 검어지거나, 파츠가 겹치거나 끊기는 결과를 완성본으로 취급하지 않는다.
- 로컬 PC의 전용 모델 8개는 설치·해시 검증됐고 Wan 14B 영상도 실행됐다. 그러나 시험 영상에서 포니테일이 사라져 미승인. 모델, 도구, 비용과 게임 검수 결과를 혼동하지 않는다.
- 다음 담당자는 위 인수인계의 원본·검수용 GIF·모델 출처를 먼저 확인하고, 포니테일과 장비 유지 및 프레임별 일관성을 검증한다. 유료 호출은 기존 승인 범위와 구별한다.
- 정본 원격은 `ver04`의 `game-dev-team_ver04`, 루트가 플러그인 정본이고 `plugins/game-dev-team/`은 미러다. 메모리는 편의 기록이며 사람 승인 및 review-loop 정본을 대체하지 않는다.
