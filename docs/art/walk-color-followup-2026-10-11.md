# SCAIL 걷기 밝기 보정 v3

## [주장]

사용자가 좋아진 모션을 유지하면서 14·15번의 어두워짐을 수정해 달라고 요청했고 코드 후처리를 승인했다. 인접한 13~17번에 나타난 색 변화에만 단조 RGB 곡선을 적용했다. 생성 모델 재실행은 없다. 결과는 concept 상태다.

## [증거]

대상 코드 커밋: `48413a5` (이번 산출물은 작업 트리의 별도 파일).

- [동시 재생 비교](../../out/sprite-lab/scail2-sword-v2-color-v3-review/compare.html): 원본과 보정본을 같은 프레임으로 재생한다.
- [보정 코드](../../out/sprite-lab/correct-walk-color.mjs), [곡선·원본 해시·보존 검증](../../out/sprite-lab/scail2-sword-v2-color-v3/color-qa.json).
- 기준 프레임 11·12·18·19의 foreground 채널별 분위수를 사용했다. 검정 0과 흰색 255는 고정한다. 512px와 기존 128px 출력에 같은 곡선을 적용하고 리샘플링하지 않는다.
- 14번 foreground 중앙 RGB 가중 밝기: 16.94→46.39; 15번: 26.67→51.32. 비교 기준 주변 프레임은 48.25~58.33이다. 이 값은 gamma RGB 가중치이며 물리적 휘도가 아니다.
- 파일을 다시 읽어 확인한 알파 변경 픽셀: 512px와 128px 모두 **0**. 프레임 수 25, 캔버스·좌표 유지. 13~17번 외의 512px 프레임은 원본과 파일 해시가 같다.
- [스프라이트 판정 원문](../../out/sprite-lab/scail2-sword-v2-color-v3-qa/sprite-qa.md): **exit 1**. 색 드리프트 미달은 없고 형태 미달 1건·경고 4건이 남았다. 색 보정을 전체 아트 게이트 통과로 보고하지 않는다.

## [기준]

알파·크기·프레임 수·픽셀 좌표를 유지한다. 어두운 구간의 밝기를 주변 범위에 가깝게 맞추고 동시 재생으로 깜빡임·색 변화를 사람이 확인한다.

## [공백]

브라우저 실제 재생 조작과 게임 내 검수는 미실행이다. PNG 비교를 직접 확인하고 프리뷰 HTTP 응답을 확인했다. 생성된 캐릭터의 새 모션이나 장비를 만들지 않았다.

## [잔여 위험]

검정으로 잘린 원본의 디테일은 색 곡선으로 복구할 수 없다. 옷·망토·장비의 세부 색 변화가 남을 수 있으므로 보정본의 사람 검수가 필요하다. 기존 실루엣·컷아웃 경고는 이번 색 보정 범위 밖이다.
