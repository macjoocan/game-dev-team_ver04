# 집 결과와 현재 B 비교

## [주장]

사용자 요청에 따라 집에서 만든 Ludo 선택본과 은발 검사 ComfyUI 결과를 한 화면에 놓았다. 현재 GPT B도 참고용으로 추가했다. 이번 작업에서는 새 이미지를 생성하거나 원본 동작을 수정하지 않았다.

## [증거]

대상 커밋: `4c43b68`. 비교 페이지와 자료는 로컬 실험 산출물이다.

- [비교 재생](index.html)
- [프레임 출처·SHA-256·타이밍](comparison.json)
- Ludo 원본: `samples/art-comparison-2026-10-16/ludo-cycle/walk/`
- 집 ComfyUI 원본: `samples/2d-sprite-motion-pilot/video-probe-walk.gif`
- 현재 B 원본: `out/experiments/gpt-walk-20261106/gpt-sheet/frames/`

Ludo 24장의 해시를 기존 선택본 manifest와 대조했고 모두 일치했다. ComfyUI는 보존된 GIF를 12장으로 해독했다. GIF 파일도 그대로 복사했다. B 8장은 파일을 그대로 복사했다.

브라우저에서 이미지 로드, 같은 주기·0.5배속 선택, 진행 슬라이더를 확인했다. 아래는 브라우저 검사 반환값이다. 자연스러움 판정은 포함하지 않는다.

```json
{"mode":"cycle","speed":"0.5","end":[23,11,7],"start":[0,0,0],"reportStatus":200,"images":[{"loaded":24,"total":24},{"loaded":12,"total":12},{"loaded":8,"total":8}]}
```

## [기준]

| 클립 | 프레임 | 보존된 비교 타이밍 |
|---|---:|---|
| 집 Ludo | 24 | 13.5 FPS, 약 1.78초. 과거 원본 영상 길이에서 추정한 비교 속도 |
| 집 ComfyUI | 12 | GIF의 각 80ms, 총 0.96초 |
| 현재 GPT B | 8 | 현재 실험의 각 125ms, 총 1초 |

‘보존된 속도’는 위 타이밍을 사용한다. ‘같은 주기’는 세 클립을 약 1.78초로 맞춘다. 0.5배 재생과 수동 진행 이동도 제공한다. 같은 주기가 같은 발 자세의 대응을 뜻하지는 않는다.

첫 프레임의 피사체 범위를 기준으로 표시 크기와 중심을 고정했다. 프레임마다 재정렬하거나 크기를 바꾸지 않았다. 흰 배경과 워터마크는 보존했다.

## [공백]

세 클립은 같은 캐릭터·같은 모델·같은 입력 조건이 아니다. 서비스의 일반적인 품질 순위를 판정하는 실험이 아니다. 원본 GIF 이전의 고해상도 전체 프레임과 서비스의 실제 개별 프레임 타이밍은 확보하지 않았다. 새 모션 생성이나 최종 자연스러움 승인도 하지 않았다.

## [잔여 위험]

Ludo 선택본에는 무료 출력 워터마크가 있다. 집 ComfyUI 결과는 포니테일이 사라지는 외형 문제가 있다. 현재 B는 발 접지와 반복 경계를 더 확인해야 한다. 움직임의 선호와 원화 보존을 따로 판단한 뒤 후속 개선 경로를 선택한다.
