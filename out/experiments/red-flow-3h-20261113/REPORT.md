# 적발 3등신 · 동작 연결과 발 먼지

## 주장

이동·공격·백스텝을 같은 위치에서 이어 재생하는 검토본이다. 빠른 연타는 예약하고, 올려 베기 뒤에는 검을 내리는 4개 자세를 거친다. 걷기와 달리기의 위상을 이어 쓰며, 멈출 때는 발을 딛는 자세를 넣었다.

사용자가 먼지가 캐릭터에 가린다고 지적해 그리는 순서를 고쳤다. 먼지는 캐릭터 다음에 그린다. 발이 닿은 바닥에 남고 진행 방향 뒤로 퍼진다. 기존 대기·공격 PNG 48장은 바꾸지 않았다.

## 기준

버튼 입력으로 월드 위치를 초기화하지 않는다. 발 먼지는 착지·발 접촉·정지에만 낸다. 백스텝 공중 구간에서는 내지 않는다. 모션 감소 설정은 먼지·검 궤적·파편·화면 흔들림을 끈다. 새 프레임은 기존 캔버스·피벗·팔레트를 따른다.

## 공백

Unity 연동, 실제 검 충돌, 회피 무적은 구현하지 않았다. 적중은 지정한 타이밍과 거리로 확인하는 시연이다. 프로젝트 공통 art-gate는 기존 샘플 누락으로 exit 3이며, 이번 프리뷰의 실패와 구분한다. 전체 동작의 자연스러움은 사람 검수 대기다.

## 잔여 위험

새 두 클립의 도트 계약 미달과 기존 공격 클립의 형태·도트 미달이 남아 있다. 자세 연결은 준비한 프레임을 골라 이어 주는 방식이며 모든 임의 전환을 새로 그린 것은 아니다. 발 먼지가 관절 오류를 고친다는 뜻은 아니다.

조작: A/D 또는 방향키 이동, Shift 달리기, J 연타, Q/E 스킬, Space 백스텝, R 초기화. 자동 시연만 한 주기가 끝나면 처음 위치로 돌아간다.
