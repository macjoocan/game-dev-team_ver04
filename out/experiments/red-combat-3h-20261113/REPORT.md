# 3등신 적발 용병: 3연타와 스킬 2종

## 주장

승인한 3등신 용병으로 가로 베기·올려 베기·내려찍기, 돌진 찌르기·회전 베기를 만들었다. 새 공격 40장과 기존 대기 v2 8장을 사용한다. 비교 페이지에서 연타 입력과 개별 동작을 확인할 수 있고, 이펙트 포함 GIF 6종을 제공한다.

결과는 사람 검수용 후보다. 실제 게임 엔진에 반영하거나 프로덕션으로 승격하지 않았다. 기준 커밋은 `cdd14a658c801bfa3d07a2492c3a2ecb4adbb6b0`이다.

## 기준

J를 처음 누르면 1타가 시작된다. 후속 입력 두 번까지 예약해 2타·3타로 이어간다. 키를 누르고 있을 때 발생하는 반복 이벤트는 무시한다. Q는 돌진 찌르기, E는 회전 베기, R은 시작 위치로 돌아간다.

1타의 낮은 검 자세에서 2타를 시작하고, 2타의 높은 자세에서 3타로 이어간다. 공격을 끝낸 위치는 유지한다. 비교용 반복 재생은 한 시퀀스가 끝나면 처음 위치에서 다시 시작한다. 개별 동작 버튼과 Q·E도 비교를 위해 위치를 초기화한다.

공격·타격 정지·이펙트 값은 [feel.json](feel.json)에 모았다. 표적과의 거리로 적중을 판단하며, 빗맞으면 타격 정지와 불꽃이 나오지 않는다. 회전은 정해 둔 두 시점에 적중을 확인한다. 수치와 타격 시점은 이 프리뷰를 위해 정한 값이다.

원본 시트의 희미한 알파 픽셀이 이웃 자세를 이어 붙였다. 알파 128 이상인 연결 성분으로 40개 몸체를 분리했다. 칼끝 여백을 위해 원본을 320px 캔버스에 옮긴 뒤 PixelOE로 120px 도트를 만들었다. 캐릭터의 표시 크기는 이전 3등신과 맞췄다. 기존 32색 팔레트를 공유한다.

가로 베기의 찌르기처럼 보이던 자세와 내려찍기에서 검이 보이지 않던 자세를 수정했다. 해당 두 셀만 수정 시트에서 가져왔고 나머지는 첫 생성 시트에서 가져왔다. 원본·수정 시트와 프롬프트를 이 폴더에 보존했다.

## 공백

- 표적 판정은 미리 정한 거리와 시점으로 동작한다. 실제 검 선분·궤적 충돌은 아니다.
- 실루엣 검사는 크게 회전하거나 몸을 뻗는 자세를 미달로 판정했다. 이 결과만으로 자세가 잘못됐거나 문제가 없다고 단정할 수 없다.
- 일부 도트 노이즈, 팔·검 연결, 방향 회전의 자연스러움은 사람 검수가 필요하다.
- 실제 엔진 아틀라스·카메라·전투 중첩 화면·성능·사운드는 검증하지 않았다.
- 새 연속 공격과 스킬에 대한 사람 승인은 아직 받지 않았다. 기존 대기 v2에 대한 긍정 피드백을 새 공격의 승인으로 확대하지 않았다.

## 잔여 위험

단독 동작보다 연결 구간에서 자세 차이가 더 잘 보일 수 있다. 0.5배속과 이펙트 끄기로 손목·검·발을 함께 확인해야 한다. 여러 효과가 겹치는 실제 게임 화면에서는 깜빡임 검사를 다시 해야 한다.

GPT 이미지 도구로 자세를 만들었고 이후 변환·입력·연출·GIF는 로컬에서 처리했다. 추가 유료 모션 API는 호출하지 않았다.

재현 순서는 `prepare-components.mjs`, `pixelize.py`, `normalize.py`, `create-feel.mjs`, `tune-contact.mjs`, `build.mjs`다. PixelOE는 기존 D 드라이브 Python 환경에서 `-X utf8`로 실행한다. 브라우저 캡처와 GIF 출력은 `qa/capture.json`, `export.py`, `verify-flash.mjs`를 사용한다.
