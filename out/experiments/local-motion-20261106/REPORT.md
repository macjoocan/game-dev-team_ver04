# 은발 검사 로컬 걷기 수정

## 주장

칼 잘림과 주기적인 색 변화를 개선한 C안을 만들었다. GPT 원화와 기존 Ludo 걷기를 입력으로 썼다. 추가 유료 생성은 0회다. 현재 상태는 사람 검수 대기다.

사용자는 A안의 모션을 좋게 평가했다. 칼 잘림과 일부 프레임의 색 차이를 지적했고, 이미지가 기준보다 커서 잘린다고 추정했다. 원본 프레임에서 칼이 오른쪽 경계를 넘는 것을 확인했다.

- A: 384×448, 시간축을 나눠 VAE 디코딩. 칼 잘림과 12·24번 부근 색 변화·잔상.
- B: 전체 VAE 디코딩. 색 변화·잔상 개선, 칼 잘림은 남음.
- C: 같은 입력에 좌우 48px, 위아래 32px 여백을 추가. 480×512로 다시 생성했다. 입력 픽셀 크기는 유지했다.
- 대조 실험: B의 같은 latent를 A의 타일 설정으로 다시 디코딩했다. 색 변화와 잔상이 같은 구간에 재현됐다. 생성 모델의 색 불안정만으로 설명할 문제가 아니었다.

## 증거

대상 저장소 커밋은 `4c43b68`이며 작업 트리 변경이 있다. 실험은 이 폴더에 분리했다. 원화와 기존 Ludo 자료는 덮어쓰지 않았다.

| 확인 | 결과 | 원시 자료 |
|---|---|---|
| C 생성 | 성공, 서버 기록 488.51초 | `c-motion-run.json`, `server.stderr.log` |
| 같은 latent 디코딩 대조 | 타일 방식에서 색 변화 재현 | `decode-check-run.json`, `decode-check/contact.png`, `b-motion/contact.png` |
| 투명 처리 | CPU, 26장, 206.99초 | `c-alpha/alpha-report.json` |
| 경계 접촉 | 26장 모두 0, 오른쪽 최소 24px | `c-preview/bounds.json` |
| 자동 정합성 | exit 1, 형태 미달 1건·경고 4건 | `qa/sprite-qa.stdout.txt`, `qa/sprite/sprite-qa.json` |
| 루프 측정 | 0.95, 경계 비율 1.24, smooth | `qa/loop.stdout.txt` |
| 아틀라스 | exit 0, 2048×2088, 점유율 81.4% | `qa/atlas.stdout.txt` |
| 브라우저 | 비교 4종, 각각 26장 로드 | `dashboard.png`, `compare.html` |

자동 정합성의 색 드리프트는 최대 0.013이었다. 형태 미달은 9~14번 프레임의 대표 자세 대비 실루엣 IoU 0.47~0.49다. 임계값 0.5를 낮춰 통과시키지 않았다. 16번 떨림과 고아 섬·구멍·반투명 경고도 보존했다. 머리카락 사이와 다리 사이의 정상 빈 공간이 구멍 수치에 포함될 수 있다. 모든 경고가 오탐이라고 단정하지 않는다.

`sprite-qa` JSON의 atlas 항목은 null이었다. 아틀라스 점유율은 별도 `atlas-pack` 출력으로만 확인했다. Ludo CLI의 exit 0은 실행 성공이며 아트 승인과 다르다.

## 기준

칼끝이 모든 프레임의 캔버스 안에 남아야 한다. 머리카락·망토·의상의 색을 유지하고, 기존 걷기와 발 교차·접지를 비교한다. 같은 픽셀 배율과 14.4fps로 재생한다. 이 fps는 기존 영상에서 추정한 값이다.

모든 프레임은 480×512이며 별도로 확대·축소하거나 실루엣 중심에 재정렬하지 않았다. 프레임마다 중심을 다시 맞추면 칼의 움직임이 몸의 좌우 이동으로 바뀔 수 있다. 발 기준점 후보는 Ludo metrics의 (260,462)이며 실제 엔진에서 확인해야 한다.

실행 조건: RTX 5060 8GB, Wan Animate 2 INT8, LightX2V LoRA, seed 7, 6 steps, CFG 1, lcm/simple. 그래프와 입력 해시는 실행 기록에 있다. ComfyUI 커밋은 `c9d8a6e69c4b5ab7fa0f789e7b988c172cd31fc9`다. 생성 모델은 기존 D 드라이브 파일을 재사용했다.

## 공백

실제 엔진 임포트·작은 목표 화면·바쁜 전투 화면 검수는 하지 않았다. 다른 캐릭터나 새 동작도 시험하지 않았다. 기존 유료 Ludo 동작을 참조한 결과이므로 독립적인 무비용 동작 생성 능력을 입증한 것은 아니다. 로컬 실행의 전기·장비 비용은 별도다.

생성 모델 SHA-256은 이번에 다시 검증하지 않았다. 배경 제거 모델의 MD5만 알려진 값과 대조했다. 작업 시작 art-gate는 기존 샘플 누락으로 exit 3이었다. `docs/pipeline/state.json`이 없어 열린 게이트 상태는 미확인이다.

## 잔여 위험

자동 형태 미달과 떨림·알파 경고가 남아 있다. 루프 도구는 거의 정지한 한 구간도 표시했다. 칼 길이와 자세의 미세 변화, 선명한 가장자리의 잔여 흔들림은 사람 검수가 필요하다. 프로덕션 승인·Git 커밋·push는 하지 않았다.

비교 화면: `http://127.0.0.1:8197/compare.html`. 재실행은 기존 요청 ID를 먼저 조회한다. `run-graph.mjs`는 같은 실행 기록이 있으면 자동 재제출하지 않는다.

원시 도구 출력은 `qa/`에 보존했다. 위 표는 탐색용 요약이며 원시 출력의 판정을 대신하지 않는다.
