# 데브팀 0.51.0 기능 보강 완료 보고

## [주장]

요청한 1~3번을 구현했다. 이어서 엔진 공통 2D·3D 이펙트 제작과 검수를 추가했다.

1. 게임성 게이트: 자원·잠금·순서의 클리어 가능성 검사, 사람의 플레이 기록, 기록 사이 시뮬레이션 2회 예산을 연결했다. 기록이 없는 기존 프로젝트는 예산 제한을 적용하지 않는다.
2. 설치 검사: Claude·Codex의 실제 활성 설치본에서 배포 파일 목록과 SHA-256을 비교한다. 같은 버전의 누락·변경·추가도 찾는다. 공식 설치 스크립트는 설치 뒤 다시 검사한다.
3. 열린 과제: REVIEW.md의 오래된 3D·설치·게임성 항목을 현재 구현과 맞췄다. 남은 과제와 과거 기록은 구분해 보존했다.

FX는 스펙·팔레트에서 2D 프레임/시트와 3D 링 메시/파티클 모션을 만든다. 공통 manifest, 재생 프리뷰, 해시·규격·예산 검사도 제공한다. 독립 검증에서 찾은 반복 프리뷰의 0.5초 정지를 수정했다.

## [기준]

테스트는 정상 경로뿐 아니라 입력 누락, 잘못된 자원/순서 모델, 기록 위조용 줄바꿈, 예산 소진, 동일 버전 파일 누락, 산출물 변조, 예산 초과를 확인한다. FX 재생성은 실행 경로를 포함한 로그를 제외하고 에셋 바이트가 같아야 한다.

규격 검사 exit 0은 검사 범위 충족, 1은 미달, 3은 측정 불가다. 테스트 통과와 사람 승인·게임의 재미·출시 승인은 별개다.

## [공백]

- 실제 Unity·Godot·Unreal·Web 어댑터, GPU 시간·드로우콜·중첩 장면은 아직 검증하지 않았다.
- 3D 제작 범위는 burst/orbit 파티클과 링 메시다. 연기·리본·액체·볼륨·구체형 보호막 표면은 포함하지 않는다.
- 브라우저 연결이 없고 Chrome 접근 승인이 시간 초과됐다. 실제 HTML 화면 조작은 미확인이며, 이미지 확인과 DOM 스텁 검증만 수행했다.
- 기존 art-gate는 사라진 샘플 경로 때문에 측정 불가다. [기준 보고서](../history-baseline/art-gate-report.md)를 보존했다.
- docs/pipeline/state.json이 없어 열린 게이트는 미확인이다. 승인 여부를 새로 만들지 않았다.
- CI는 Windows 로컬 실행이다. Ubuntu 원격 CI와 실제 게임의 모델 정확성은 별도 확인이 필요하다.

## [잔여 위험]

FX는 concept 상태다. 외형·가독성·실제 화면 플래시와 라이선스 승인이 남았다. glTF BLEND만으로 가산 합성이 적용되지 않으므로, 엔진 어댑터가 manifest의 재질 계약을 적용해야 한다.

설치 파일은 갱신됐지만 현재 세션의 스킬 재로드는 확인하지 않았다. Claude는 /reload-plugins, Codex는 새 세션에서 사용한다. 커밋·원격 push는 수행하지 않았다.
