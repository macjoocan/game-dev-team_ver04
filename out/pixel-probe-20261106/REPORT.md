# 은발 걷기 PixelOE 변환 시험

## 주장

사용자가 기억한 도구는 PixelOE다. 공식 GitHub를 확인한 뒤 은발 걷기 26장을 변환했다. 원본과 단순 축소, PixelOE 64·96·128px를 비교할 수 있다. 추가 유료 호출은 0회다. 변환·파일 출력 시간은 11.59초이며, 소스 다운로드와 Python 로딩 시간은 포함하지 않는다.

사용자는 이번 결과에 “와우 좋네 ㅋㅋㅋ”라고 긍정 평가했다. 특정 해상도를 선택하거나 생산용으로 승인한 것은 아니다. 64px는 얼굴과 머리카락 세부가 많이 줄었다. 정지 화면에서 96·128px는 비교할 만하지만, 갑옷의 잔무늬는 거칠게 남는다. 자동 도트 검사는 네 후보 모두 미달이다.

## 증거

- 공식 소스: [KohakuBlueleaf/PixelOE](https://github.com/KohakuBlueleaf/PixelOE). 버전 1.0.1, 커밋 `7ce444b36d3876a151d845d4493240e904454d89`, Apache-2.0. 로컬 설치본은 확인하지 못해 실험 폴더에 새로 받았다.
- 실행: `run-pixeloe.py`, PyTorch 2.13.0+cu130, 로컬 CUDA. 빠진 OpenCV 5.0.0.93만 `deps/`에 설치했다. AI 모델을 추가로 받거나 이미지를 재생성하지 않았다.
- 입력: `out/experiments/local-motion-20261106/c-alpha/`의 PNG 26장. 변환 뒤 원본 SHA-256이 모두 그대로임을 확인했다.
- 결과: 후보당 26장, 총 104장. 캔버스 경계 접촉은 모든 후보에서 0/26이다. 각 프레임은 최대 32색, 반투명 픽셀은 0이다.
- 자동 검사 원시 출력: [단순 축소](qa/nearest96.stdout.txt), [PixelOE 64](qa/pixeloe64.stdout.txt), [PixelOE 96](qa/pixeloe96.stdout.txt), [PixelOE 128](qa/pixeloe128.stdout.txt). 모두 exit 1이다. 색·알파 조건을 지켜도 외톨이 픽셀 비율이 현재 도구의 35% 상한을 넘는다. 96px 첫 프레임은 49.4%다.
- 명령·종료 코드: [qa/execution.json](qa/execution.json). 입력·출력 해시와 설정: [export/manifest.json](export/manifest.json). 검증 대상 저장소 커밋: `59b1ab7`.
- 브라우저에서 이미지 130개를 모두 불러왔다. 확대·원래 크기용 캔버스 10개와 프레임 이동을 확인했다. 이미지 로딩 오류는 0이다. 최초 favicon 404는 데이터 아이콘으로 수정했다.

## 기준

원본 480×512와 같은 비율을 유지한다. 64·96·128은 캐릭터 키가 아니라 캔버스 높이다. 출력 크기는 각각 60×64, 90×96, 120×128이다. 프레임별 잘라내기나 재중앙 정렬은 하지 않는다. 재생 시간은 프레임당 70ms로 맞췄다.

PixelOE 설정은 `pixel_size=4`, `thickness=2`, `mode=contrast`, `backend=torch`다. RGB에 윤곽 확장과 축소를 적용했다. 투명도는 원본 마스크를 별도로 축소해 128 기준으로 이진화했다. 투명 영역의 검정이 색에 섞이지 않도록 가까운 경계의 RGB를 먼저 확장했다.

프레임마다 팔레트를 새로 뽑지 않는다. 원본 26장 전체에서 공통 32색을 만들고, 단순 축소와 PixelOE 결과 모두 Pillow로 같은 팔레트에 맞췄다. 따라서 이 결과는 **PixelOE RGB 변환 + 공통 팔레트 + 원본 알파 처리**의 조합이다. PixelOE 기본 출력만의 품질로 일반화하지 않는다. 디더링은 사용하지 않았다.

## 공백

PixelOE의 다른 축소 방식, 윤곽 두께, 색 수와 후처리 강도는 아직 비교하지 않았다. 픽셀 격자가 맞고 색 수가 적다는 사실만으로 사람이 그린 도트와 같다고 주장하지 않는다. 루프 중 작은 픽셀의 흔들림, 얼굴 가독성, 무기 두께는 사람 검수가 필요하다. 실제 게임 엔진에서는 확인하지 않았다.

시작 art-gate는 기존 샘플 경로 누락으로 측정 불가였다. 열린 게이트 원장도 없다. 이번 후보의 도트 검사는 별도로 실행했고 그 미달을 그대로 보존했다.

## 잔여 위험과 재개

칼날·머리카락은 원래 작은 요소라 축소하면서 끊기거나 흔들릴 수 있다. 고정 팔레트는 새 색 발생을 막지만 픽셀 위치의 떨림까지 막지는 않는다. 다음에는 사람이 선택한 크기에서 잔무늬 정리와 색 수를 비교한다. 원본과 이번 결과를 먼저 보존한다.

```powershell
python3 -m http.server 8199 --bind 127.0.0.1 --directory out/pixel-probe-20261106
```

비교 주소: `http://127.0.0.1:8199/`. [정지 비교](comparison.png)와 [128px 걷기 GIF](pixeloe128.gif)도 있다. 사용자의 후속 요청에 따라 결과물·스크립트·검사 기록을 Git 전달 대상으로 정리했다. 재실행 절차와 남은 작업은 [최신 인수인계](../../docs/handoffs/2026-11-06.md)에 있다.
