# GPT 은발 검사 시작 이미지

## [주장]

ComfyUI 결과 대신 내장 GPT 이미지 생성 도구로 단일 시작 이미지를 만들었다. 원본의 긴 은발 포니테일·청록 망토·갑옷·부츠·검을 참고했다. 아직 미승인 검수 후보이며, 영상이나 걷기 시트는 만들지 않았다.

## [증거]

- 결과: [silver-swordswoman-gpt-v1.png](silver-swordswoman-gpt-v1.png)
- 생성 도구: 내장 `image_gen` (CLI·ComfyUI 사용 안 함). 세부 모델 버전은 도구에서 제공하지 않았다.
- 전체 생성 프롬프트: [prompt.txt](prompt.txt)
- 입력: `samples/2d-sprite-motion-pilot/reference-keypose.png`
- 파일 해시·출처·상태: [manifest.json](manifest.json)

## [기준]

한 명의 전신, 긴 포니테일, 두 팔·두 손·두 다리, 완전한 부츠와 검을 확인했다. 보이는 범위에서 검을 쥔 손과 손잡이·가드·칼날이 연결돼 있다. 생성된 이미지는 원본과 동일한 파일이 아니며, 세부 형태는 달라졌다.

## [공백]

프레임 사이 정체성·손과 검의 동작 연결·걷기 자연스러움은 검사하지 않았다. 실제 게임 화면과 목표 표시 크기도 아직 확인하지 않았다. 투명 배경으로 생성했지만, 가장자리 알파 품질의 수치 검사는 하지 않았다. 사람 승인은 없다.

## [잔여 위험]

외곽에 가는 밝은 테두리와 색 잔여물이 보일 수 있다. 게임 배경 위에서 확인하고 최종 알파를 정리해야 한다. 단일 프레임의 외형이 좋아도 애니메이션에서 유지된다는 보장은 없다. 입력과 결과의 프로덕션 사용 권리는 이번에 검토하지 않았다.
