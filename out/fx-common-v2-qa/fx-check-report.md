# FX 규격 검사

## [주장]
판정: **충족**. 에셋 규격만 검사했다.

## [증거]
fx.impact.2d: 12프레임, 텍스처 442368 bytes, 파티클 0, 삼각형 0
fx.pulse.2d: 24프레임, 텍스처 884736 bytes, 파티클 0, 삼각형 0
fx.burst.3d: 24프레임, 텍스처 4096 bytes, 파티클 24, 삼각형 96
fx.orbit.3d: 32프레임, 텍스처 4096 bytes, 파티클 16, 삼각형 96

## [기준]
파일 SHA-256·프레임/시트 규격·제작 스펙과 모션/메시 일치·지정 예산. 텍스처는 RGBA32 추정이며, 모든 효과 1개씩 동시 사용을 가정한 합계다.

## [공백]
실제 엔진의 GPU 시간·드로우콜·오버드로·깊이 정렬은 미측정
실제 화면의 중첩·시야 면적·플래시 안전은 별도 검사 필요
가독성·색각이상 대체 신호·타이밍 체감·외형 승인·라이선스 허가는 사람 검수 필요

## [잔여 위험]
파일 해시는 출처 인증이 아니다. concept 산출물은 사람 승인 전 프로덕션에 반영하지 않는다. glTF의 BLEND는 additive를 보장하지 않으므로 엔진에서 manifest의 재질 계약을 적용한다.
